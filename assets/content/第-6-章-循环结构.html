第 6 章　循环结构

高频考点6.1 三种循环的语法与执行流程

C
/* ① for —— 初始化、条件判断、条件控制写在一起 */for (初始化语句; 条件判断语句; 条件控制语句){    循环体语句;}​/* ② while —— 先判断，后执行 */初始化;while (条件判断语句){    循环体语句;    条件控制语句;}​/* ③ do...while —— 先执行，后判断（至少执行一次！） */初始化;do{    循环体语句;    条件控制语句;} while (条件判断语句);

重难点高频考点6.2 for vs while vs do-while 的执行次数对比

循环 判断时机 循环体执行次数 适用
for / while 先判断，后执行 0 次 ~ n 次 次数可能为 0
do...while 先执行，后判断 1 次 ~ n 次 循环体至少执行一次

教材经典对比（附录 D 第 18 条）：

C
int a=0, i;scanf("%d",&i);​/* while：先判断 */while (i<=10) { a=a+i; i++; }​/* do-while：先执行 */do { a=a+i; i++; } while (i<=10);

当输入 i > 10 时：while 的循环体一次都不执行（a 保持 0）； do-while 的循环体执行一次（a = i）。 这就是二者结果不同的原因。

高频考点 高频辨析题：「do-while 循环至少执行一次」——对，这是它与 for/while 唯一的本质差别。

易错点6.3 易错点 22：for 后多写分号

C
for (i = 0; i < 5; i++);      // ❌ 循环体变成空语句！{    scanf("%d", &x);    printf("%d", x);}// 本意：输入 5 个数并输出；实际：只输入 1 个数就输出，然后结束

附录 D 原文：「由于 for() 后多加了一个分号，使循环体变为空语句，此时只能输入一个数并输出它」

高频考点6.4 循环的三大语句

6.4.1 break —— 跳出循环

  • 作用：立即结束整个循环；
  • 只能跳出最内层的那一层循环；
  • 在 switch 中，break 结束的是 switch（不是循环）。

6.4.2 continue —— 跳过本次循环

  • 作用：结束本次循环，跳到下一次循环；
  • ⚠️ 在 for 循环中，continue 会跳到条件控制语句（即 i++），然后重新判断条件；
  • ⚠️ 在 while / do-while 中，continue 会跳到条件判断语句—— ⚠️ 如果条件控制语句写在循环体末尾，continue 会导致它被跳过 → 死循环！
C
/* ❌ 死循环 */while (i <= 100) {    if (i == 50) continue;   // 跳过了 i++    sum += i;    i++;}​/* ✔ 正确：把 i++ 提到 continue 之前，或改用 for */while (i <= 100) {    if (i == 50) { i++; continue; }    sum += i;    i++;}

高频考点 高频考点：这就是为什么 for 比 while 更安全——for 的 i++ 在循环头，不会被 continue 跳过。

高频考点6.4.3 goto —— 无条件跳转

C
int i = 1, sum = 0;label1:    sum = sum + i;    i++;    if (i <= 100) goto label1;printf("%d\n", sum);
  • 配合标号使用：标号名: 语句
  • 可以跳到任意位置；
  • 辨析延伸 一般只用于跳出循环（如多层嵌套循环中直接跳到最外层）；
  • 易错点 工程建议：能用 break/continue 就不要用 goto，可读性差、易出错。

高频考点6.5 循环嵌套

C
for (i = 0; i < 2; i++)    for (j = 0; j < 2; j++)        for (k = 0; k < 2; k++)            printf("%d %d %d\n", i, j, k);
  • 内层循环完整执行完毕后，外层才继续；
  • 总执行次数 = 各层循环次数相乘（上例 2×2×2 = 8 次）；
  • break 只跳出它所在的那一层循环。

高频考点 经典题：3 层嵌套 for，问 printf 执行几次、最后一次打印什么？ 答：3×3×3=27 次；最后一次 i=2, j=2, k=2（若从 0 开始到 2）。

6.6 循环中的常见算法模式

模式 代码 用途
累加 sum += i; 求和
累乘（阶乘） s = s * i; 阶乘、连乘积
计数 count++; 满足条件的个数
求最大值 if (a[i] > max) max = a[i]; 注意 max 要用第一个元素初始化
求最小值 if (a[i] < min) min = a[i]; 同上
逆序输出 for (i = n-1; i >= 0; i--) 倒序
数字反转 j = j*10 + m%10; m = m/10; 回文数判断
位数统计 n = n / 10; 循环次数即位数 —

int max = 0;              // ❌ 若数组全是负数，结果错误！int max = a[0];           // ✔ 用第一个元素初始化for (i = 1; i < n; i++) if (a[i] > max) max = a[i];

6.7 循环中的常见输入处理技巧

C
/* 技巧 1：限制输入范围，非法则重输（教材 lt02-15.c） */for (i = 0; i < num; i++) {    scanf("%d", &a[i]);    if (a[i] <= 0) i--;        // 相当于重新输入这一轮}​/* 技巧 2：输入字符直到回车（教材 lt06-04.c） */int n = 0;while (getchar() != '\n') n++;​/* 技巧 3：配合 while 读多行（教材 lt06-09.c） */char c = '\0';while (c != '\n' && c != '\r' && c != Esc) {    c = getch();    if (c != Esc) printf("%c", c);}

⚠️ 注意：技巧 1 中若 scanf 读到非法字符（如字母），该字符会滞留在输入缓冲区导致死循环。 稳妥做法：scanf(" %d", &a[i]); 或在循环里 fflush(stdin);。

6.8 死循环与循环控制综合

死循环写法 说明
while(1){...} 合法，配合 break 使用（教材 lt06-09.c）
for(;;){...} 合法，无限循环
continue 跳过了条件控制语句 逻辑死循环
scanf 读入非法字符未清除 输入型死循环

高频考点 教材 lt06-09.c 的"无限循环 + Esc 键退出"是经典题型：

C
#include <stdio.h>#include <conio.h>#define Esc 27int main(void){  int i=0; char c;  while (1) {                      /* 无限循环 */     c = '\0';                     /* 初始化值 */     while (c != '\n' && c != '\r' && c != Esc) {        c = getch();        if (c != Esc) printf("%c", c);     }     if (c == Esc) break;          /* 按 Esc 跳出无限循环 */     i++; printf("\nThe No. is %d\n", i);  }  printf("The end.");}
