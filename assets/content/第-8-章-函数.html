第 8 章　函数

高频考点8.1 函数的定义与声明

C
/* 函数定义 */返回值类型 函数名(形参表){    函数体;    return 返回值;}​/* 函数声明（原型）—— 放在调用之前 */int max(int a, int b);

易错点 易错点 35：形参表中的每个参数都要独立写类型！

C
int max(int a, b) { }    // ❌ 错误int max(int a, int b) { } // ✔ 正确
教材 lt08-02.c 明确注释了这一点。

声明与定义的区别：

函数声明 函数定义
内容 int max(int a, int b); 带 { } 的完整代码
作用 告诉编译器"有这么个函数" 真正实现功能
必需性 被调用在前时必需 必需

辨析延伸 若函数定义在调用之前，可以不写声明。教材 lt08-02.c 注释：「函数定义在函数使用前面，这里声明可省」。

高频考点8.2 参数传递

8.2.1 值传递（默认）

C
void swap(int a, int b) {   // 形参是实参的副本    int t = a; a = b; b = t;}int main(void) {    int x = 1, y = 2;    swap(x, y);    printf("%d %d\n", x, y);   // ⚠️ 输出 1 2，值没变！}

结论：值传递无法改变实参的值。函数内部改的都是副本。

8.2.2 地址传递（指针）—— 让实参真正改变

C
void swap(int *p1, int *p2) {  // 形参是指针    int t = *p1; *p1 = *p2; *p2 = t;}int main(void) {    int x = 1, y = 2;    swap(&x, &y);    printf("%d %d\n", x, y);   // ✔ 输出 2 1}

高频考点 教材对比实验（lt09-04.c vs lt09-05.c）是本知识点最经典的设计： - lt09-04.c：交换指针指向的内容 → *p1 = *p2 → 实参 a、b 的值交换 ✔ - lt09-05.c：交换指针本身（只是让两个指针变量互换指向） → 实参 a、b 的值不变 ✘

C
/* lt09-05.c —— 看似正确，实则无效！ */void swap(int *p1, int *p2) {    int *p;    p = p1; p1 = p2; p2 = p;    /* 只改了形参副本里的指针 */}

8.2.3 数组作为参数 → 传递的是地址

C
void aver(float a[5]) { ... }   /* 等价于 void aver(float *a) */void aver2(float a[], int n) { ... }   /* 需同时传长度 */

高频考点 结论：把数组传给函数，函数内修改数组元素会影响实参（因为传的是首地址）。 但数组长度不会传递，所以常需要额外传一个 n 参数（教材 lt08-12.c）。

辨析延伸 教材 lt08-09.c / lt08-10.c / lt08-11.c / lt08-12.c 是同一题的四种写法演化： 固定长度 → 传长度参数 → [] 形式 → 带 n 参数。

8.3 返回值

C
int  max(int a, int b) { return (a > b) ? a : b; }void printLine(void)   { printf("..."); }              /* 无返回值 */double aver(float a[5]) { ...; return av; }             /* 返回浮点 */

高频考点 规则： 1. 函数只能返回一种类型； 2. void 函数不能有返回值（return; 合法，return 值; 非法）； 3. return 语句会立即结束函数； 4. int 函数忘记写 return 会返回垃圾值（警告 C4716: must return a value）。

辨析延伸 一个函数最多只能返回一个值。要返回多个值，用指针参数或结构体。 教材 lt10-08-1.c 演示了用 float * 和 int * 参数返回"总分"和"不及格人数"两个值。

高频考点8.4 变量作用域与生命周期

重难点8.4.1 四种存储类别

类别 关键字 作用域 生命周期 初值
自动变量 auto（默认） 所在块内 进入块创建，退出块释放 随机值（未初始化）
静态变量 static 文件/函数块 整个程序运行期间 0（自动初始化）
外部变量 extern 从声明处到文件末尾 整个程序运行期间 0
寄存器变量 register 所在块内 同 auto 随机值

高频考点 static 局部变量的核心考点（教材 lt08-16.c / lt08-17.c）：

C
int fun(int a) {    auto  int b = 0;    /* 每次调用都重新初始化为 0 */    static int c = 3;   /* 只初始化一次，保留固定存储单元 */    b = b + 1;    c = c + 1;    return (a + b + c);}/* 3 次调用中 c 依次为 4、5、6（每次先 c=c+1 再 return） */
辨析延伸 实测：printf("%d %d %d\n", fun(1), fun(1), fun(1)); 输出 6 5 4 （GCC 从右往左求值，所以显示为倒序；c 本身确实经历了 3→4→5→6）。 static 变量在函数调用之间保值，可用于"计数器""状态保存"。

高频考点 register：建议编译器把变量放在 CPU 寄存器中以加速。现代编译器基本忽略此关键字， 且 register 变量不能取地址。

高频考点 extern：用于跨文件访问全局变量（教材 lt08-19.c ~ lt08-20-file2.c）：

C
/* file1.c */extern A, B;          /* 声明 A、B 在别处定义 *//* file2.c */static int A = 13, B = -8;   /* 实际定义 */
⚠️ 教材 lt08-20.c 的 file2.c 中 static int A=13,B=-8; 用了 static， 意味着只有本文件可见，file1.c 中的 extern A,B; 会链接失败。这是教材的瑕疵， 实际应写 int A=13, B=-8;（去掉 static）才能跨文件访问。

重难点高频考点8.4.2 作用域遮蔽（Shadowing）

C
int main(void){    int i = 2, j = 3, k;    k = i + j;    {        int k = 8;                        /* 内层块的新变量 k，遮蔽外层 k */        printf("%d\n", k);                /* 输出 8 */    }    printf("%d\n", k);                    /* 输出 5 —— 外层的 k 未被改变 */}

高频考点 与你的笔记对应：「main 函数内定义过一个 a，又在 for 循环中定义了另外一个 a， for 循环中的 a 生命周期只在 for 循环中，出循环后的 a 与 main 函数内的 a 一致」—— 原理是内层块变量遮蔽外层同名变量，且内层变量出了作用域就销毁。

高频考点 同名全局 vs 同名局部（教材 lt08-15.c）：

C
int a = 3, b = 5;          /* 全局 */int max(int a, int b) {    /* 形参 a、b 遮蔽全局 a、b */    int c;    c = a > b ? a : b;     /* 用的是形参 */    return c;}
规则：就近原则——局部优先于全局，形参优先于全局，块内优先于块外。

重难点高频考点8.5 递归函数

定义：函数自己调用自己。必须有一个终止条件。

C
long func(int n) {    long f;    if (n < 0) printf("n<0, input error");    else if (n == 0 || n == 1) f = 1;      /* 递归终止条件 */    else f = func(n-1) * n;                  /* 递归调用 */    return f;}

经典递归模型：

模型 递推关系 代码
阶乘 n! = n × (n-1)! 教材 lt08-06.c
斐波那契 f(n) = f(n-1) + f(n-2) 教材 lt08-25.c
汉诺塔 移动 n-1 → 移 1 → 移 n-1 教材 lt08-07.c
辗转相除求 gcd gcd(a,b) = gcd(b, a%b) 教材 lt08-33-2.c
数位逆序输出 先递归输出高位，再输出个位 教材 lt08-26.c

高频考点 递归三要素： 1. 终止条件（base case）—— 没有它就是无限递归 → 栈溢出； 2. 递推关系—— 把大问题化为同类小问题； 3. 递归方向—— 必须收敛到终止条件。

辨析延伸 数位逆序的巧妙写法（教材 lt08-26.c）：

C
void convert(int n) {    int i;    if ((i = n / 10) != 0) convert(i);   /* 先处理高位 */    putchar(n % 10 + '0');               /* 再输出个位 */}

8.6 函数中的常见错误

错误 后果 正确做法
形参漏写类型 编译错误 每个形参都写类型
未声明就调用 编译错误（C99+） 先声明或先定义
void 函数 return 值; 编译错误 改用 return; 或改返回类型
数组参数漏传长度 越界 额外传 n
int 函数无 return 返回垃圾值 补 return
递归无终止条件 栈溢出崩溃 加 base case
全局变量同名遮蔽 逻辑错误 改名或用局部变量
