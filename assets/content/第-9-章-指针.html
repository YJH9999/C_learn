重难点第 9 章　指针

指针是 C 语言最强大也最容易出错的特性。考试重点：概念辨析、地址与值、指针运算、指针与数组、与函数配合。

高频考点9.1 指针的基本概念

C
int a = 5;int *p = &a;      /* p 保存 a 的地址 */​printf("%d\n", a);    /* 5   —— 变量值 */printf("%d\n", *p);   /* 5   —— 解引用，取出 p 指向的值 */printf("%p\n", &a);   /* 地址 */printf("%p\n", p);    /* 同上，&a 与 p 数值相同 */

三个关键概念：

概念 符号 说明
地址 &a 变量在内存中的位置
指针变量 int *p 存储地址的变量，本身也有地址 &p
解引用 *p 取出该地址存放的值

高频考点 关键：p 是"a 的地址"，*p 是"a 的值"，&p 是"p 自己的地址"。 教材 lt09-02-2.c 的经典对照：

C
printf("%d %x\n", *pointer_1, &*pointer_1);/* &*p 等价于 p —— 先解引用再取地址，得到原地址 */

高频考点9.2 指针的声明与初始化

C
int  *p1;              /* int 型指针 */int  *p2 = &a;         /* 初始化为 a 的地址 */int  *p3 = a;          /* ❌ 错误！类型不匹配（a 是 int 不是地址） */char *p4 = "hello";    /* 字符指针指向字符串常量 */int  **pp = &p1;       /* 指针的指针（二级指针） */

易错点 易错点 35：int *p = a; —— a 的值是 5，不是地址。编译器只给警告但结果错误。

重难点高频考点9.3 指针的运算

运算 含义 说明
p + n 指向 p 之后第 n 个元素 实际地址增加 n × sizeof(*p) 字节
p - n p 之前第 n 个元素
p - q 两个指针相差的元素个数 只有同一数组的指针才能相减
p++ / ++p 指向下一个元素 ⚠️ 顺序不同但单独语句中效果相同
p-- 指向上一个元素
*p 解引用
&*p 等价于 p
*&p 等价于 p

高频考点 核心理解：p+1 不是"地址加 1 字节"，而是"加一个元素的大小"。

C
int  *p;    /* p+1 地址增加 4 字节 */double *q;  /* q+1 地址增加 8 字节 */char  *r;   /* r+1 地址增加 1 字节 */

易错点 易错点 36（指针自增的"陷阱"）：教材 lt09-02-2.c 中

C
printf("%x %x\n", (pointer_1)++, pointer_1++);
① (pointer_1)++ 是表达式，其值是自增前的地址，但副作用（p 加 1）何时发生未定义； ② 第二个 pointer_1++ 又是另一个未定义行为； ③ 两次 printf 之间的求值顺序也未定义。 结论：这种写法行为不可预测，绝不要在实际代码中这么写。

重难点高频考点9.4 指针与数组

核心等价关系（教材 lt09-10.c vs lt09-11.c 是最佳例证）：

C
int a[10];/* 下面两种写法完全等价 */a[i]       ≡  *(a + i)
C
/* lt09-10.c —— 下标法 */for (i=0;i<10;i++) a[i] = i;/* lt09-11.c —— 指针法 */for (i=0;i<10;i++) *(a+i) = i;

其他等价：

表达式 等价表达式
a &a[0]（首元素地址）
a[i] *(a+i)
&a[i] a+i
*a a[0]

高频考点 但有本质区别： - a 是数组名，是常量（不可修改），a++ 是语法错误； - p 是指针变量，可以 p++。

C
int a[10], *p = a;a++;      // ❌ 数组名不是可修改的左值p++;      // ✔

高频考点9.5 指针的分类

分类 例子 说明
普通指针 int *p 指向一个 int 变量
数组指针 int (*p)[10] 指向整个数组（含行数信息）
函数指针 int (*p)(int,int) 指向函数
字符指针 char *p 常用于字符串操作
空指针 NULL / 0 不能解引用
野指针 未初始化的 int *p; 易错点 指向随机地址，解引用会崩溃
悬空指针 已释放内存的指针 易错点 解引用是未定义行为

易错点 易错点 37（野指针）：

C
int *p;          /* ⚠️ p 的值是随机垃圾 */*p = 10;        // ❌ 可能崩溃
必须初始化：int *p = NULL; 或 int *p = &a;

易错点 易错点 38（数组名 vs 指针）：

C
char a[10], b[10];scanf("%s", a);b = a;          // ❌ 语法错误：数组名不可赋值strcpy(b, a);   // ✔

高频考点9.6 指针与函数

9.6.1 用指针实现"输出多个值"

C
void aver(struct student stu, float *total, int *count);/* 调用 */aver(stu[i], &total, &c);

9.6.2 函数返回指针

C
char *getStr(void) {    static char buf[20] = "hello";    return buf;      /* 返回首地址 */}

⚠️ 不能返回局部变量的地址（函数返回后栈帧销毁 → 悬空指针）。

9.6.3 函数指针

C
int (*fp)(int, int);     /* 指向"两个 int 参数、返回 int"的函数 */fp = max;printf("%d\n", fp(3, 5));

9.7 指针运算实战：数组最大值

C
int a[10] = {3, 7, 1, 9, 2};int *p = a, *pmax = a;for (p = a + 1; p < a + 10; p++)    if (*p > *pmax) pmax = p;printf("max=%d\n", *pmax);

辨析延伸 教材 lt09-03.c 用指针交换来实现求最大最小值：

C
if (a < b) { p = p1; p1 = p2; p2 = p; }   /* 交换指针的指向 */printf("max=%d,min=%d\n", *p1, *p2);
注意：这里 a、b 的值没有变，只是 p1、p2 指向变了。

高频考点9.8 指针常见错误速查

写法 问题
int *p; *p = 5; 野指针，未初始化
int a[3]; a = b; 数组名不可赋值
scanf("%s", &str); 数组名不需 &
char *p = "abc"; p[0]='X'; 修改字符串常量，未定义行为
int *p = &a; p = p + 1; 后再 *p 越界（若 p 已指向数组末尾）
int **pp; **pp; 二级指针未初始化
return &local_var; 返回局部变量地址 → 悬空指针
free(p) 后再用 p 释放后未置 NULL → 悬空指针

📝 40.c　指针解引用与间接修改

C40.c
#include<stdio.h>​int main(){    int a =10;​    int* p=&a;​    printf("%d\n",*p);​    *p=200;​    printf("%d\n",*p);​    return 0;}

辨析延伸 要点 *p 读、*p=200 写——通过地址直接改内存，这是理解后面所有指针题的起点。

📝 44.c　指针遍历数组

C44.c
#include <stdio.h>​int main()​{    // 1.定义数组​    int arr[] = {10,20,30,40,50};​    int len = sizeof(arr) / sizeof(int);​    // 2.获取数组的指针​    // 实际上获取的：数组的首地址​    int* p1 = arr;​    //int* p2 = &arr[0];​    // 3.利用循环和指针遍历数组获取里面的每一个元素​    for (int i = 0; i < len; i++)​    {        printf("%d\n", *p1++);    }​    //*p1++ <==> *p1);p1++;​    return 0;}

辨析延伸 要点 *p1++ 等价于「取 *p1 的值，然后 p1 后移」——++ 优先级高于解引用，但后置 ++ 先用后加。

📝 47.c　指针数组装三个不同长度的一维数组

C47.c
#include <stdio.h>​int main()​{    // 1.定义三个一维数组​    int arr1[3] = {1,2,3};​    int arr2[5] = {1,2,3,4,5};​    int arr3[9] = {1,2,3,4,5,6,7,8,9};​    // 预先计算每一个数组真实的长度​    int len1 = sizeof(arr1) / sizeof(int);​    int len2 = sizeof(arr2) / sizeof(int);​    int len3 = sizeof(arr3) / sizeof(int);​    // 再定义一个数组，装所有数组的长度​    int lenArr[3] = {len1, len2, len3};​    // 2.把三个一维数组放入到指针数组当中​    // 数组的数据类型，跟内部存储的元素类型保持一致​    // arr1: 使用数组名进行计算的时候，退化为指向第一个元素的指针，此时不再表示数组的那个整体了​    // 指针 --- 内存地址  64位win  8个字节​    int* arr[3] = {arr1, arr2, arr3};​    // 3.利用索引遍历arr​    for (int i = 0; i < 3; i++)​    {        // i : 依次表示指针数组的索引 0 1 2​        for (int j = 0; j < lenArr[i]; j++)​        {            printf("%d ", arr[i][j]);        }​        printf("\n");    }​    return 0;}

辨析延伸 要点 int* arr[3] 是指针数组（3 个 int*）；数组名赋值时退化为首元素指针，所以要另存长度数组。

📝 48.c　数组指针遍历二维数组

C48.c
#include <stdio.h>​int main()​{    // 1.定义一个二维数组​    int arr[3][5] =​    {        {1,2,3,4,5},​        {11,22,33,44,55},​        {111,222,333,444,555}    };​    // 2.利用指针遍历二维数组​    // 获取二维数组的指针​    // 数组指针的数据类型: 要跟数组内部元素的类型保持一致​    // 二维数组里面存储的是一维数组int[5]​    int(*p)[5] = arr;​    for (int i = 0; i < 3; i++)​    {        // 遍历一维数组​        for (int j = 0; j < 5; j++)​        {            printf("%d ", *(*p + j));        }​        // 换行​        printf("\n");​        // 移动二维数组的指针，继续遍历下一个一维数组​        p++;    }​    return 0;}

辨析延伸 要点 int(*p)[5] 是数组指针（指向含 5 个 int 的一维数组），与 int* arr[3] 恰是孪生易混点；*(*p + j) 取元素，p++ 跳一整行。

📝 49.c　二级指针遍历

C49.c
#include <stdio.h>​int main()​{    // 1.定义三个一维数组​    int arr1[5] = {1,2,3,4,5};​    int arr2[5] = {11,22,33,44,55};​    int arr3[5] = {111,222,333,444,555};​    // 2.把三个一维数组的内存地址，存入指针数组​    int* arr[3] = {arr1, arr2, arr3};​    // 3.获取二级指针​    int** p = arr;​    // 4.遍历数组​    for (int i = 0; i < 3; i++)​    {        for (int j = 0; j < 5; j++)​        {            printf("%d ", *(*p + j));        }​        // 换行​        printf("\n");​        // 移动指针​        p++;    }​    return 0;}

辨析延伸 要点 int** p = arr（指针数组名退化为首元素地址，即 int**）；*(*p+j) 与 p++ 配合遍历，逻辑与 48 题一致。

📝 52.c　字符数组 vs 指针字符串

C52.c
#include <stdio.h>​int main(void)​{    // 1.利用字符数组 + 双引号的方式定义字符串​    char str1[4] = "abc";​    printf("修改前 str1：%s\n", str1);​    // 字符数组内容可以修改​    str1[0] = 'Q';​    printf("修改后 str1：%s\n\n", str1);​    // 2.利用指针 + 双引号的方式定义字符串​    char* str2 = "abcd";​    char* str3 = "abcd";​    printf("str2 的地址：%p\n", str2);​    printf("str3 的地址：%p\n", str3);​    // str2 和 str3 地址一样，常量区复用​    // str2[0] = 'Q';   // 错误！只读常量区，不能修改，打开会崩溃​    return 0;}

重难点 注意 重点辨析：char str1[4]="abc" 在栈上、可修改；char* str2="abcd" 指向只读常量区，修改会崩溃。相同字面量编译器只存一份（str2 与 str3 地址相同）。
