第 12 章　预处理与宏

12.1 预处理命令概述

指令 作用
#include 文件包含：把指定头文件的内容插入到当前位置
#define 宏定义：文本替换
#undef 取消宏定义
#if / #ifdef / #ifndef / #elif / #else / #endif 条件编译
#error 编译时出错
#pragma 编译器特定指令
#line 改变行号/文件名

高频考点 关键理解：预处理发生在编译之前，是纯文本层面的操作，编译器还看不到这些指令。

重难点高频考点12.2 #define 宏 vs const 只读变量（重点对比）

C
#define aa (23*34+5)      /* 宏定义：预处理阶段文本替换 */
const int bb = 23*34+5;  /* const 修饰的只读变量 */

两者求值都是 782 + 5 = 787，但机制完全不同：

特性 #define 宏 const 只读变量
处理阶段 预处理（编译之前） 编译阶段
本质 纯文本替换 真正的变量
类型检查 ❌ 无 ✅ 有严格类型检查
内存占用 ❌ 不占内存 ✅ 占内存（数据段）
内存地址 ❌ 不能 &aa ✅ 可以 &bb
作用域 从定义处到文件末尾（可 undef） 遵循变量作用域规则（块级/函数级）
调试支持 ❌ 调试器看不到（已被替换） ✅ 可被调试器识别
能否作数组长度 C89 允许，C++ 允许 C99+ 允许（C89 不允许）
复杂类型 ❌ 多行需加 \，易错 ✅ 支持结构体等复杂类型
可修改 — ❌ 修改编译报错
C
const int bb = 787;
bb = 100;    /* ❌ 编译报错：只读 */

高频考点宏的最大陷阱：优先级

C
#define A 1+2
int x = A*3;
/* 预处理后 → x = 1+2*3 = 7  （不是 9！） */

宏表达式外面必须加括号：

C
#define A (1+2)
int x = A*3;    /* → (1+2)*3 = 9  ✔ */

高频考点 函数式宏的参数也要加括号（教材 lt12-05.c ~ lt12-08.c 完整对比）：

C
#define SQ(y) (y)*(y)         /* 参数没括号 */
#define SQ(y) ((y)*(y))       /* ✔ 正确形式 */
测试：sq = SQ(a+1); - (y)*(y) → (a+1)*(a+1) = 正确 - y*y → a+1*a+1 = a + (1*a) + 1 = 错！ 测试：sq = 160/SQ(a+1); - (y)*(y) → 160/(a+1)*(a+1) = 错（先算除再算乘） - ((y)*(y)) → 160/((a+1)*(a+1)) ✔

高频考点 多参数宏的致命陷阱（教材 lt12-11.c）：

C
#define SSSV(s1,s2,s3,v) s1=l*w;s2=l*h;s3=w*h;v=w*l*h;
这里 s1=l*w; 中的 l、w、h 是宏体内的自由变量，不是参数！ 必须写成：
C
#define SSSV(l,w,h,s1,s2,s3,v) s1=l*w; s2=l*h; s3=w*h; v=w*l*h;

宏 vs 函数的选型

场景 推荐
需要类型安全、需要调试、局部常量 const
条件编译 #ifdef / #ifndef #define（唯一选择）
简单文本替换、头文件保护 #define
函数式宏（带参数） #define（但要警惕参数重复计算）
需要 switch 的 case 值 #define（const 变量在 C89 中不能作 case 值）

高频考点12.3 头文件保护宏

C
#ifndef __STUDENT_H
#define __STUDENT_H

struct student { int num; };

#endif

作用：防止同一个头文件被重复包含（重复包含会导致重复定义错误）。

高频考点12.4 条件编译

C
#define NUM ok

#ifdef NUM                 /* 如果定义了 NUM */
    printf("Number=%d\n", ps->num);
#else
    printf("Name=%s\n", ps->name);
#endif
C
#define R 1
#if R                      /* 相当于 #if 1 */
    r = 3.14159 * c * c;
#else
    s = c * c;
#endif
指令 含义
#if 表达式 表达式为真（非 0）时编译
#ifdef 标识符 标识符已定义时编译
#ifndef 标识符 标识符未定义时编译
#elif 表达式 上一分支未成立时的次选
#else 最后的兜底
#endif 结束条件编译块

辨析延伸 教材 lt12-12.c / lt12-13.c 是条件编译的标准范例。

12.5 宏定义的其他技巧

C
/* 宏 + 运算符 */
#define PI 3.14159
#define AREA(r) (PI * (r) * (r))

/* 定义字符串宏 */
#define P printf
#define D "%d\n"
#define F "%f\n"
P(D F, a, b);      /* 展开为 printf("%d\n""%f\n", a, b); */

⚠️ 相邻字符串常量会自动拼接："%d\n""%f\n" → "%d\n%f\n"。

高频考点 宏定义的经典错误（教材 lt12-01.c 对照）：

C
#define M (y*y+3*y)     /* 正确：整体加括号 */
s = 3*M + 4*M + 5*M;    /* 展开成 3*(y*y+3*y) + 4*(...) + 5*(...)  ✔ */
若写成 #define M y*y+3*y，则 3*M → 3*y*y+3*y = 完全错误。
