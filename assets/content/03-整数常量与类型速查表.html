0.3 整数常量与类型速查表

类型 关键字 字节 取值范围（典型 32 位 int） 输出格式
字符型 char / signed char 1 −128 ~ 127 %c（字符）/ %d（ASCII）
无符号字符 unsigned char 1 0 ~ 255 %u
短整型 short 2 −32768 ~ 32767 %hd
无符号短整型 unsigned short 2 0 ~ 65535 %hu
整型 int 4 −2147483648 ~ 2147483647 %d
无符号整型 unsigned int 4 0 ~ 4294967295 %u
长整型 long 4 (Win) / 8 (Linux 64) 同 int 或更大 %ld
无符号长整型 unsigned long 4 / 8 ≥ 0 %lu
长长整型 long long 8 ±9.22×10¹⁸ %lld
无符号长长整型 unsigned long long 8 0 ~ 1.84×10¹⁹ %llu
单精度浮点 float 4 ≈ ±3.4×10³⁸，有效数字 6~7 位 %f
双精度浮点 double 8 ≈ ±1.8×10³⁰⁸，有效数字 15~17 位 %f
扩展精度浮点 long double 8 / 16 有效数字 18~19 位 %Lf

⚠️ 实测提醒：部分 Windows 编译器（MinGW）对 long double 的 printf 支持不完善，用 %Lf 可能输出异常值。 考试与作业建议统一使用 double。

高频考点 后缀速记：L/l → long；LL/ll → long long；U/u → unsigned；F/f → float；无后缀的小数字面量一律是 double。 辨析延伸 后缀不写编译器通常也能通过，但强烈建议写上：写 1000L 能避免整型溢出，写 3.14F 能避免隐式转换成 double 带来的多余精度。
