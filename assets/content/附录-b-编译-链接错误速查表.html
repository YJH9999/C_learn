附录 B　编译 / 链接错误速查表

B.1 严重错误（fatal error）

错误码 含义 常见原因
C1004: unexpected end of file found 文件意外结束 少一个 }，或字符串/注释未闭合
C1083: Cannot open include file: 'xxxx.h' 找不到包含文件 头文件路径错 / 拼写错 / 忘了加 #include

B.2 编译错误（error）

错误码 含义 常见原因
C2001: newline in constant 常量中出现换行 字符/字符串常量缺 ' 或 "；多行字符串需续行符 \
C2006: #include expected a filename #include 缺文件名 写成 #include <stdio.h> 漏了尖括号或引号
C2008: '=' : unexpected in macro definition 宏定义中不该有 = 宏定义写成 #define A = 1（不要写 =）
C2015: too many characters in constant 字符常量字符太多 'ab' 是非法的（只能 1 个字符）
C2018: unknown character '0x##' 未知字符 全角符号、全角字母、汉字
C2041: illegal digit '#' for base '8' 八进制非法数字 八进制数里出现了 8 或 9
C2057: expected constant expression 需要常量表达式 case 后跟了变量；int a[n] 中 n 是变量
C2059: syntax error 语法错误 附近有错（常是上一行漏分号）
C2061: syntax error : identifier 'main' main 附近语法错 常见于漏分号、括号不配对
C2064: term does not evaluate to a function 项不是函数 忘了 #include 头文件；函数名写错
C2065: 'xxxx' : undeclared identifier 标识符未定义 变量没声明就用；名字拼写错误
C2078: too many initializers 初始化值太多 数组长度小于初值个数
C2105: '++' needs l-value ++ 需要可赋值量 对常量或表达式自增：5++
C2106: '=' : left operand must be l-value 左边必须可赋值 a+b = c
C2109: subscript requires array or pointer type 下标只用于数组或指针 对普通变量用 []
C2133: 'xxx' : unknown size 不知道大小 数组未定义大小又未初始化
C2137: empty character constant 空字符常量 '' 两个单引号之间没内容
C2143: syntax error : missing ';' before ... 少分号 最常见的语法错误
C2146: syntax error : missing ... before identifier 缺类型 变量漏写类型
C1966: case value 'x' already used case 值重复 switch 中两个 case 值相同
C2198: 'xxx' : too few actual parameters 实参太少 函数调用参数个数不够
C2224: left of '.xxx' must have struct/union type 左边必须是结构体 对非结构体用 .
C2374: 'xxxx' : redefinition; multiple initialization 重复定义 同一变量定义两次
C2449: found '{' at file scope 文件范围出现 { 少函数首部，或多了 {
C2466: cannot allocate an array of constant size 0 数组大小为 0 int a[0];

B.3 警告（warning）—— 仍能编译，但大概率是错

错误码 含义 真实风险
C4013: 'printf' undefined printf 未定义 ⚠️ 忘了 #include <stdio.h>
C4024: different types for formal and actual parameter 形参与实参类型不同 隐式转换，可能出错
C4035: 'f': no return value return 没有返回值 函数声明与定义不一致
C4047: '=' : 'char *' differs from 'char[2]' 字符指针与字符数组不兼容 scanf("%s", &str)
C4133: '=' : incompatible types - from 'int *' to 'float *' 指针类型不兼容 严重错误，必须改
C4244: conversion from 'int' to 'float', possible loss of data 可能丢失数据 隐式类型转换，注意截断
C4305: truncation from 'const double' to 'float' 双精度截断为单精度 精度损失
C4307: '+' : integral constant overflow 整型常量溢出 改用 L 后缀或拆开
C4552: '<' : operator has no effect 操作符无效 多余的运算符
C4700: local variable 'xxx' used without having been initialized 局部变量未初始化 易错点 最高危警告，结果随机
C4716: 'fun' : must return a value 需要返回值 函数会返回垃圾值

高频考点 重点关注：C4013（忘头文件）、C4700（未初始化）、C4133（指针类型不兼容）、 C4047（数组名加了 &）—— 这四个是本课程最高频的警告。

B.4 链接错误（link error）

错误码 含义 原因
LNK1168: cannot open Debug/P1.exe for writing 无法写入 exe 程序还在运行，先关掉
LNK2001: unresolved external symbol _main 找不到 main 缺少 main 函数，或拼写错误
LNK2001: unresolved external symbol xxx 找不到符号 ① 调用库函数但忘写头文件；② 自定义函数名写错；③ 该函数在另一个 .c 文件中且未加入工程
LNK2005: _main already defined in xxx.obj main 重复定义 一个工程里有两个 main

高频考点 经典教训：教材 lt08-20.c 就是把 file1.c 和 file2.c 合并在一个文件里的版本—— 如果直接复制粘贴两个文件的内容到同一个 .c 文件，会出现 LNK2005: _main already defined。
