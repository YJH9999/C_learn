{

    int a, b;
    double s;

    /* ② 输入（带提示信息） */

    return 0;
}

G.7 随机数 rand / srand 专题（实验高频）

C
int rand(void);              /* 返回 [0, RAND_MAX] 的伪随机整数 */
void srand(unsigned seed);   /* 设置种子；通常 srand(time(NULL)) */

种子相同 → 伪随机序列完全相同。srand(time(NULL)) 用当前时间做种子，程序每次运行序列才不同；srand 只调用一次，放进循环里会得到相同值。

范围公式（最小差值为 1）：

目标区间 公式
[a, b) rand() % (b - a) + a
[a, b] rand() % (b - a + 1) + a
(a, b] rand() % (b - a) + a + 1
0 ~ 1 浮点 rand() / (double)RAND_MAX

带最小差值 d 的随机小数（d = 10⁻ᵏ）：先放大 scale = 10ᵏ 转成整数问题，生成后再除回去。

C
/* [1.0, 2.0] 内差值 ≥ 0.01 的随机小数 */
int num = rand() % 101 + 100;    /* 整数域 [100, 200] */
double f = num / 100.0;          /* 还原 → 1.00 ~ 2.00 */

负随机数：按上述公式生成正数后取负即可。
