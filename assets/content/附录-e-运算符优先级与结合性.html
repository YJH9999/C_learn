E.3 三个高频优先级判定题

① a < b && c > d：&& 的优先级低于关系运算符 → (a<b) && (c>d) ✔

② a = b > c：> 优先级高于 = → a = (b > c) ✔

③ x | y && z == w： == > && > | → x | (y && (z == w)) ✔

高频考点E.4 教材原题解析（lt05-02.c / lt05-03.c）

C
char c='k'; int i=1,j=2,k=3; float x=3e+5,y=0.85;​printf("%d,%d\n", 'a'+5<c, -i-2*j>=k+1);/* 'a'+5 = 97+5 = 102; 102 < 'k'(107) → 1 *//* -i-2*j = -1-4 = -5;  k+1 = 4;  -5 >= 4 → 0 *//* 输出：1,0 */​printf("%d,%d\n", 1<j<5, x-5.25<=x+y);/* 1<j<5 → (1<j)<5 → 1<5 → 1 *//* x-5.25 <= x+y → 减 5.25 必然更小 → 1 *//* 输出：1,1 */​printf("%d,%d\n", i+j+k==-2*j, k==j==i+5);/* i+j+k = 6;  -2*j = -4;  6 == -4 → 0 *//* k==j → 3==2 → 0;  0 == (i+5=6) → 0 *//* 输出：0,0 */​printf("%d,%d\n", !x*!y, !!!x);/* !x = 0 (x非0为真), !y = 0 → 0*0 = 0 *//* !!!x = !(!(!x)) = !(!0) = !1 = 0 *//* 输出：0,0 */​printf("%d,%d\n", x||i&&j-3, i<j&&x<y);/* && 高于 || → x || (i && (j-3)) → x非0为真 → 1 *//* i<j → 1; x<y → 3e5 < 0.85 → 0 → 1&&0 = 0 *//* 输出：1,0 */​printf("%d,%d\n", i==5&&c&&(j=8), x+y||i+j+k);/* = 优先级低于 && 和 || → 但 (j=8) 有括号，不影响解析 *//* 真正起作用的是 && 短路：i==5 为假 → (j=8) 根本不执行 → 0 *//* x+y 非0为真 → || 短路 → 1 *//* 输出：0,1 */

高频考点 注意：i==5&&c&&(j=8) 中，因为 i==5 为假，&& 短路， 所以 (j=8) 根本没有执行，j 仍然是 2。这是短路效应的经典考题。 上面整段代码在 GCC 16 下实测输出为 1,0 / 1,1 / 0,0 / 0,0 / 1,0 / 0,1，与解析完全一致。
