重难点第 13 章　位运算

位运算是 C 的特色功能，在进制转换、压缩存储、硬件交互中极为有用。考试主要考 &、|、^、~、移位。

13.1 位运算基础

所有位运算都只作用于整数类型。

运算符 名称 运算规则 示例（a=9=1001, b=5=0101）
& 按位与 同 1 则 1 9 & 5 = 1001 & 0101 = 0001 = 1
| 按位或 有 1 则 1 9 | 5 = 1001 | 0101 = 1101 = 13
^ 按位异或 不同则 1 9 ^ 5 = 1001 ^ 0101 = 1100 = 12
~ 按位求反 各位取反 ~9 = ~1001 = ...0110 = -10
<< 左移 各位左移 n 位，低位补 0 1 << 3 = 8
>> 右移 各位右移 n 位 8 >> 3 = 1

高频考点 异或要点：a ^ b == 0 当且仅当 a == b； a ^ 0 == a（异或 0 不变）；a ^ a == 0（自身异或为 0）； 异或一个数两次会抵消——这是"不借助临时变量交换"的原理。

重难点高频考点13.2 移位运算详解

C
a << n   /* 等价于 a * 2^n （在不溢出的前提下） */a >> n   /* 等价于 a / 2^n （对非负数） */
关键点 说明
左移低位补 0 1 << 3 = 1000 = 8
右移高位补 0（unsigned） 0x80000000u >> 4 = 0x08000000
右移高位补符号位（signed） -16 >> 2 = -4（算术右移）
移位位数 ≥ 类型宽度是未定义行为 1 << 32 在 int 上是 UB

高频考点 超经典陷阱：1 << 31 会溢出（int 最高位是符号位）。 正确写法：1u << 31 或 1UL << 31。

高频考点 循环移位（教材 lt13-07.c 明确演示）：

C
b = a << (32 - n);   /* 循环左移 n 位 */c = a >> n;          /* 循环右移 n 位 */

高频考点 取某几位（教材 lt13-08.c）：

C
b = a >> (m - 1);      /* 右移到最低位 */c = b & 0x000f;        /* 或 c = b & ~(~0 << n);  取低 n 位 */

辨析延伸 位域（bit field）（教材 lt13-06.c）：

C
struct bits {    unsigned a : 1;   /* 占 1 位 */    unsigned b : 3;   /* 占 3 位 */    unsigned c : 4;   /* 占 4 位 */} bit, *pbit;
位域让结构体成员按位分配，节省空间。常用于硬件/协议解析。

高频考点13.3 位运算的实战技巧

技巧 代码 说明
判奇偶 if (n & 1) 最快的奇偶判断
判 2 的幂 if ((n & (n-1)) == 0) n > 0 时成立
交换两个数（不用临时变量） a^=b; b^=a; a^=b; 原理：异或两次抵消
提取低 4 位 x & 0x0f 掩码
设置某位为 1 x |= (1 << n) 或运算置位
清零某位 x &= ~(1 << n) 与非运算清位
翻转某位 x ^= (1 << n) 异或翻转
高低字节交换 (a << 8) | (a >> 8) 教材 lt13-05.c
二进制输出 递归逐位 (x & (1 << (n-1))) >> (n-1) 教材 lt13-09.c
C
/* 教材 lt13-05.c：把两个字符打包进一个 int */char a='a', b='b'; int p, c, d;p = a;p = (p << 8) | b;      /* 高 8 位存 a，低 8 位存 b */d = p & 0xff;           /* 取低 8 位 → 'b' */c = (p & 0xff00) >> 8;  /* 取高 8 位 → 'a' */

13.4 位运算易错点

错误 原因
~ 作用于浮点数 语法错误，位运算只支持整数
1 << 32 移位位数 ≥ 宽度，未定义行为
1 << 31 溢出 应写 1u << 31
对负数右移 有符号数右移是算术右移（补符号位），结果依实现而定
混淆 ^ 与 ** ^ 是异或，** 在 C 中不存在（那是 Python）
忘记 ^ 是不同为 1 不是"相同为 1"
