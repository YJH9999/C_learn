重难点第 14 章　堆内存管理与文件进阶（HM 课程讲义）

🧩 来源：HM 课程讲义 09–12（字符串和内存管理 / 结构体联合体 / 文件进阶）。栈由系统自动管理，堆（heap）自己申请、自己释放——这一章是 C 语言"能写大程序"的分水岭。

14.1 malloc / calloc / realloc / free

函数 原型 说明
malloc void *malloc(size_t size) 申请 size 字节，内容是垃圾值
calloc void *calloc(size_t n, size_t size) 申请 n×size 字节，自动清零
realloc void *realloc(void *p, size_t size) 把 p 指向的空间调整为 size（可扩可缩），返回新地址（可能搬移）
free void free(void *p) 释放；只能 free 堆地址，free 后立刻置 NULL

标准四步曲：

C
int *p = malloc(sizeof(int) * 10);
if (p == NULL) {                       /* 1. 必须判空！ */
    perror("malloc error");
    return -1;
}
/* 2. 使用 p[0] ~ p[9] */
free(p);                               /* 3. 释放 */
p = NULL;                              /* 4. 防野指针 */

易错点 常见错误：malloc 后不判 NULL 就用；free 两次（double free）；free 后继续读写（野指针）；只 free 内层不 free 外层（泄漏）。

14.2 二级指针与堆上的"二维"空间

C
/* 外层：3 个 int* 的数组；内层：每个指向 5 个 int */
int **p = malloc(sizeof(int *) * 3);
for (int i = 0; i < 3; i++)
    p[i] = malloc(sizeof(int) * 5);

p[i][j] = 10;          /* 使用：等价 *(*(p+i)+j) */

/* 释放：先内层，后外层 —— 顺序不能反 */
for (int i = 0; i < 3; i++) { free(p[i]); p[i] = NULL; }
free(p); p = NULL;

重难点 char **p 存字符串时写 p[i] = "hello" 是错的（把 heap 指针改指向只读常量区，free 时崩溃），要用 strcpy(p[i], "hello")。

14.3 内存操作函数（string.h）

函数 原型 要点
memset void *memset(void *s, int c, size_t n) 按字节设置；heap 申请后清零用 memset(p, 0, n)。⚠️ 置 1 是每字节都是 1：int 数组会变成 0x01010101 = 16843009，不是 1！
memcpy void *memcpy(void *d, const void *s, size_t n) 按字节拷贝任意内存（strcpy 只能拷字符串）；src/dest 重叠时行为未定义
memmove 同 memcpy 重叠安全版，拿不准就用它
memcmp int memcmp(const void *s1, const void *s2, size_t n) 按字节比较，返回 0 / 正 / 负

14.4 sprintf / sscanf 家族：一份数据三个去向

函数 数据流向 典型用途
printf 内存 → 屏幕 调试输出
sprintf 内存 → 字符数组 buf 拼接/格式化字符串（buf 要够大）
fprintf 内存 → 文件 fp 格式化写文件
scanf 键盘 → 内存
sscanf 字符串 str → 内存 从字符串里"抠"数据
fscanf 文件 fp → 内存 格式化读文件

返回值：fprintf 成功返回写入的字符个数，失败 -1；fscanf 成功返回正确匹配的个数，失败 -1。

易错点 fscanf 读数据前把接收缓冲区清空（memset(buf, 0, sizeof(buf))），否则残留旧数据会造成边界溢出；读不到匹配时会提前结束（feof 为真）。

14.5 按块读写 fwrite / fread 与 feof 判定

fgetc/fputc、fgets/fputs、fprintf/fscanf 三组默认处理文本文件；fwrite/fread 文本、二进制通吃：

C
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *fp);
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *fp);
/* 例：fwrite(&stu, sizeof(stu), 1, fp);  整块结构体写入 */

易错点 feof 经典坑：while(!feof(fp)) 先判断后读会多执行一次（读到 EOF 标志才置位）。正确姿势是先读后判：

C
while (1) {
    fscanf(fp, "%d\n", &arr[i]);
    i++;
    if (feof(fp)) break;   /* 先存储，后判断，防止最后一个元素丢失 */
}

14.6 综合案例：文件版随机数排序

生成 10 个随机数写文件 → 读出排序 → 写回同一文件：

C
void write_rand(void) {
    FILE *fp = fopen("test03.txt", "w");
    if (!fp) { perror("fopen error"); return; }
    srand(time(NULL));
    for (int i = 0; i < 10; i++)
        fprintf(fp, "%d\n", rand() % 100);
    fclose(fp);
}
/* read_rand：fscanf 循环读入（先读后判 feof）→ 冒泡排序
   → 再以 "w" 重新打开同一文件写入排好序的结果 */

14.7 strstr 与字符串函数补充

C
char *strstr(const char *str, const char *substr);
/* 成功：返回子串在原串中的位置（地址）；失败：NULL */

/* 统计 substr 在 str 中出现次数：找到后指针跳过子串长度继续找 */
int substr_times(char *str, char *substr) {
    int count = 0;
    char *p = strstr(str, substr);
    while (p != NULL) {
        count++;
        p += strlen(substr);   /* 跳过本次命中的子串 */
        p = strstr(p, substr);
    }
    return count;
}

⚠️ strcpy 不检查 dest 空间是否足够，是不安全函数；建议 strncpy（只拷 n 字节）并保证 n ≤ dest 大小。
