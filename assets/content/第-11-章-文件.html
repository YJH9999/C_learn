第 11 章　文件

11.1 文件的基本概念

文件是操作系统管理的一组相关数据。文本文件（ASCII，可读）与二进制文件（按内容存储）。

类型 打开方式 说明
文本文件 "r" / "w" / "a" / "r+" / "w+" / "a+" 按字符读写，\n 可能被转换
二进制文件 "rb" / "wb" / "ab" / "rb+" / "wb+" / "ab+" 按字节读写，不转换

模式说明：

模式 含义 文件不存在 文件存在
r 只读 打开失败 从头读
w 只写 创建（清空） 清空原内容
a 追加 创建 末尾追加
+ 读写 视基础模式 —
b 二进制 — —

高频考点 高频陷阱："w" 模式会清空已有文件！想保留原内容追加要用 "a"。

高频考点11.2 文件的打开与关闭

C
#include <stdio.h>FILE *fp;​if ((fp = fopen("c:\\project\\example\\c1.txt", "rt")) == NULL){    printf("\nCannot open file, strike any key exit!");    getch();    exit(1);          /* 标准错误处理三步：报错 → 提示 → 退出 */}​ch = fgetc(fp);while (ch != EOF) { putchar(ch); ch = fgetc(fp); }​fclose(fp);            /* ⚠️ 必须关闭！否则数据可能未写入磁盘 */

高频考点 标准错误处理模板（贯穿所有文件题）：

C
if ((fp = fopen("file.txt", "rt")) == NULL) {    printf("Cannot open file!");    getch();    exit(1);}

辨析延伸 fopen 的返回值是 FILE *（文件指针），类型定义在 <stdio.h>。 fopen 的第一个参数是字符串，所以路径要写成 "c:\\path\\file.txt"（\ 要转义为 \\）。

高频考点11.3 文件读写函数速查

分类 函数 说明
字符 fgetc(fp) 读一个字符，返回 int（用 int 接，因为要能返回 EOF）
fputc(c, fp) 写一个字符
getc(fp) / putc(c, fp) 宏形式，同上
字符串 fgets(str, n, fp) 读最多 n-1 个字符，安全，会加 '\0'
fputs(str, fp) 写字符串（不加分隔符）
块读写 fread(ptr, size, n, fp) 读 n 个 size 字节的对象
fwrite(ptr, size, n, fp) 写 n 个 size 字节的对象
定位 fseek(fp, offset, fromwhere) 移动文件指针
ftell(fp) 返回当前位置（字节）
rewind(fp) 移到文件开头
状态 feof(fp) 是否已到文件末尾（非 0 表示已到）
ferror(fp) 是否有读写错误
clearerr(fp) 清除错误和 EOF 标志
格式化 fscanf(fp, fmt, ...) 从文件格式化读
fprintf(fp, fmt, ...) 向文件格式化写
关闭 fclose(fp) 关闭文件

高频考点 fseek 的第三个参数： | 值 | 含义 | |---|---| | SEEK_SET (0) | 从文件开头 | | SEEK_CUR (1) | 从当前位置 | | SEEK_END (2) | 从文件末尾 |

高频考点11.4 高频陷阱：feof 的误用

C
/* ❌ 错误写法 —— 教材 lt11-11.c 中的 while (!feof(fin)) 就是这个坑 */while (!feof(fin)) {    fgets(str, 80, fin);        /* 最后一次会失败，str 保持旧内容 */    printf("%s", str);}​/* ✔ 正确写法 */while (fgets(str, 80, fin) != NULL) {    printf("%s", str);}

高频考点 原理：feof() 返回的是"上一次读取操作是否触及了文件末尾"的标志， 而不是"当前是否在末尾"。所以最后一次循环开始时 feof 还是 0， 但 fgets 会失败并返回 NULL，此时 str 里还是上一次的旧内容 → 多打印一行重复内容。

辨析延伸 教材 lt11-11.c 的正确处理是 if (!fgets(str,80,fin)) break; —— 思路完全一致。

高频考点11.5 文件随机读写（结构体二进制）

C
struct student { char name[10]; int num; int age; char addr[15]; } stu, *qq;FILE *fp;​qq = &stu;fp = fopen("stu_list", "rb");rewind(fp);                                  /* 移到开头（rb 模式下打开即在开头） */fseek(fp, i * sizeof(struct student), 0);    /* 定位到第 i 个记录 */fread(qq, sizeof(struct student), 1, fp);     /* 读 1 个结构体 */fclose(fp);

辨析延伸 二进制文件存结构体的优点：一条记录定长，可用 fseek 直接定位，无需逐条扫描。 教材 lt11-08.c（写）和 lt11-09.c（读）是一对完整示例。

C
int main(int argc, char *argv[]){    if (argc == 1) { printf("have not enter file name!"); exit(0); }    if ((fp1 = fopen(argv[1], "rt")) == NULL) { ... }    if (argc == 2) fp2 = stdout;                  /* 标准输出 */    else if ((fp2 = fopen(argv[2], "wt+")) == NULL) { ... }}

辨析延伸 教材 lt11-04.c 是标准范例：程序名 + 输入文件 + 输出文件。

11.7 标准流

流 指向 说明
stdin 标准输入（键盘） scanf 内部用的就是它
stdout 标准输出（屏幕） printf 内部用的就是它
stderr 标准错误 报错信息通常输出到这

辨析延伸 用 fprintf(stderr, ...) 输出错误信息，不会被重定向到文件。
