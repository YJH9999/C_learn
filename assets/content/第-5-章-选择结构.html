第 5 章　选择结构

高频考点5.1 if 语句

5.1.1 三种形式

C
/* 形式一：单分支 */if (表达式) 语句;​/* 形式二：双分支 */if (表达式) 语句1;else       语句2;​/* 形式三：多分支（else if 链） */if (表达式1) 语句1;else if (表达式2) 语句2;else if (表达式3) 语句3;else 语句4;

易错点5.1.2 易错点 17：if 后面多写分号

C
if (a % 3 == 0);   // ❌ 分号把 if 语句结束了！    i++;// 效果：无论 a 是否被 3 整除，i 都会加 1

附录 D 原文：「由于 if (a%3==0) 后多加了分号，则 if 语句到此结束，程序将始终执行 i++ 语句」

正确写法：

C
if (a % 3 == 0)    i++;

易错点5.1.3 易错点 18：if/else 后的单语句

C
if (x > 0)    y = 1;    z = 2;      // ⚠️ 不管 if 是否成立，z 都会赋值！z 不受 if 控制

规范写法：总是用花括号括起来。

C
if (x > 0) {    y = 1;}

5.1.4 悬空 else 问题

C
if (a > 0)    if (b > 0)        printf("both positive");    else               // ⚠️ 这个 else 属于内层 if！        printf("a positive, b not");

规则：else 永远与最近的、尚未匹配的 if 配对（"悬空 else"）。 防御写法：加花括号。

C
if (a > 0) {    if (b > 0) {        printf("both positive");    } else {        printf("a positive, b not");    }}

5.1.5 条件表达式的值

表达式 值
关系表达式 1（真）或 0（假）
逻辑表达式 1 / 0（C 标准实际返回值可能是操作数本身，但 if 中只关心真假）
任意非 0 数值 真
0 假

高频考点 C 语言没有布尔类型（C99 之前）。C99 引入 _Bool，C23 起有 bool/true/false。 但 0/1 的思想贯穿始终——教材 lt05-14-1.c 用 leap 变量作标志变量（1 表示闰年，0 表示非闰年）， 这是本课程的标准套路。

5.1.6 常见逻辑条件写法

C
/* 判断是否在区间内 [a, b] —— 必须用 && 连接，不能写成 a <= x <= b！ */if (x >= a && x <= b) { }     // ✔if (a <= x <= b)       { }     // ❌ 等价于 (a<=x)<=b，结果几乎总是 1​/* 判断是否在两个区间外 */if (x < a || x > b) { }        // ✔​/* 闰年 */if ((y%4==0 && y%100!=0) || y%400==0) { }​/* 字符范围判断（利用 ASCII 连续性） */if (c >= '0' && c <= '9') { }    // 等价于 isdigit(c)​/* 判断三角形三边 */if ((a+b>c) && (b+c>a) && (c+a>b)) { }

易错点 易错点 19：a <= x <= b 是最经典的逻辑错误。 解析：先算 a <= x（得 0 或 1），再算 0/1 <= b（几乎恒为真）。

高频考点5.2 switch 语句

5.2.1 语法

C
switch (表达式){    case 常量表达式1: 语句1; [break;]    case 常量表达式2: 语句2; [break;]    ...    [default: 语句n;]}

高频考点5.2.2 使用细节（教材明确要求）

项目 规则
表达式 计算结果只能为字符或整数（不能是浮点数）
case 的值 只能是字符或整数的字面量，不能是变量
case 的值 不允许重复（否则 error C1966: case value already used）
break 表示中断、结束，结束整个 switch 语句
default 所有情况都不匹配时执行；可写在任意位置，甚至可省略
穿透方向 只往下穿，不会回到上面

易错点 易错点 20：case 后跟变量是语法错误：

C
int n = 1;switch (x) { case n: ... }   // ❌ error C2057: expected constant expression

易错点5.2.3 易错点 21：case 穿透（漏写 break）

C
switch (grade){    case 'A': printf("85~100\n");   // ❌ 漏 break    case 'B': printf("70~84\n");    case 'C': printf("60~69\n");    case 'D': printf("<60\n");    default: printf("error\n");}// 输入 'A' → 会依次打印 4 行！

case 穿透的执行规则（教材原文）：

  1. 根据小括号中表达式的结果去匹配对应的 case；
  2. 执行对应 case 里面的代码；
  3. 执行过程中遇到 break 就直接结束整个 switch； 如果没有遇到 break，就继续执行下面 case 中的代码，直到遇到 break 或所有代码执行完；
  4. 穿透只会往下穿，不会回到上面。

正确写法：

C
switch (grade){    case 'A': printf("85~100\n"); break;    case 'B': printf("70~84\n");  break;    case 'C': printf("60~69\n");  break;    case 'D': printf("<60\n");    break;    default: printf("error\n");}

5.2.4 多个 case 合并（fall-through 的正确用法）

C
switch (month){    case 1: case 3: case 5: case 7: case 8: case 10: case 12:        days = 31; break;    case 4: case 6: case 9: case 11:        days = 30; break;    case 2:        days = (y%4==0 && y%100!=0) || y%400==0 ? 29 : 28;        break;}

5.2.5 switch vs if 的选型

场景 推荐
有限个确定值的匹配（约 10 个 case 以内） switch
范围判断（score >= 90） if
复杂组合条件 if

辨析延伸 教材原文：「switch：有限个 case 进行匹配的情况，10 个左右；if：一般是对一个范围进行判断」

5.2.6 switch 的其他特性

  • switch 表达式不要求是常量（可以是一个变量表达式），只是 case 后的值必须是常量；
  • default 可以省略，但最好保留（万一没有匹配，程序会什么都不做）；
  • switch 体内不能有变量声明（C89 中），需要在外部声明或在内部用复合语句包裹。

5.3 条件运算符 ?:（三目运算符）

见 §3.9.6。要点：

C
max = (a > b) ? a : b;      // 求最大min = (a < b) ? a : b;      // 求最小x = cond ? 1 : -1;          // 取符号
  • 优先级：高于赋值，低于关系运算符；
  • 结合方向：从右向左（a ? b : c ? d : e = a ? b : (c ? d : e)）；
  • 三目表达式的类型由 ? 和 : 两部分的公共类型决定。
