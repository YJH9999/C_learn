第 4 章　顺序结构与输入输出（核心章节）

本章的 printf / scanf 格式控制是期末考试、实验、作业的绝对高频区，也是"程序能编译但结果错"的重灾区。

4.1 顺序结构的特点

程序按语句书写顺序自上而下逐条执行，没有选择和循环。典型三段式：

C
int main(void){    /* ① 变量定义 */    int a, b;    /* ② 输入 */    scanf("%d%d", &a, &b);    /* ③ 数据处理 + 输出 */    printf("%d\n", a + b);    return 0;}

4.2 printf 函数

语法：printf("格式控制字符串", 输出项表列);

  • 格式控制串中的普通字符原样输出；
  • % 开头的格式说明按对应类型转换输出；
  • 输出项表列中的参数个数必须与格式说明个数一一对应，多一个少一个都是未定义行为。

重难点高频考点4.3.1 关于 %f 与 %lf 的终极结论

输入 double 用 %lf，输入 float 用 %f；输出 double 和 float 统一用 %f。

原因： - printf 的参数经过默认实参提升（default argument promotion）：float 被提升为 double。 所以 printf 里的 %f 必须能同时接住 float（已提升为 double）和 double，用 %f 即可。 - scanf 没有这种提升，它按格式符精确从内存读取指定字节数。 %f 只写 4 字节（float），%lf 写 8 字节（double）。

C
float f;  double d;scanf("%f", &f);    // ✔scanf("%lf", &d);   // ✔printf("%f", f);    // ✔printf("%f", d);    // ✔
  • ❌ scanf("%f", &d); → 只填了低 4 字节，高 4 字节是未初始化的垃圾值；
  • ❌ printf("%lf", d); → 不标准。虽然某些编译器兼容，但可移植性差，阅卷按标准判错。

📌 实验要求原文：「在 C 语言标准中，%lf 被保留给 scanf 用于读取 double，%f 给 scanf 读取 float。输出 double 时应使用 %f。」

高频考点4.3.2 %c 与 %s 的关键区别

%c %s
读入内容 1 个字符 一整串字符（到空格/回车为止）
空白处理 不跳过空格、回车、Tab ——它们都是有效字符 自动跳过前导空白
变量 char ch; → scanf("%c", &ch); char str[20]; → scanf("%s", str);（不加 &）

易错点 易错点 14（经典陷阱）：

C
char ch1, ch2, ch3;scanf("%c%c%c", &ch1, &ch2, &ch3);
若输入 a b c，则：ch1='a'，ch2=' '（空格），ch3='b'。 因为 %c 只取 1 个字符，不需要空格分隔。

解决办法：格式串中加空格跳过空白 → scanf(" %c %c %c", &ch1, &ch2, &ch3); 或改用 scanf("%s", buf) 读整行。

辨析延伸 scanf 的 前导空格技巧：scanf(" %c", &ch); —— 格式串开头的空格会先丢弃所有前导空白，是解决 %c 吞空格的通用手法。

高频考点4.3.3 什么时候加 &（取地址符）

变量 写法 原因
普通变量 int a; scanf("%d", &a); 需要传地址，scanf 才能写回
字符数组 char str[20]; scanf("%s", str); 数组名本身即首元素地址，加了 & 类型不匹配
二维数组 int a[3][4]; scanf("%d", &a[0][0]); 取具体元素地址

易错点 易错点 15：scanf("%s", &str); —— &str 是整个数组的地址（char (*)[20]）， 与 %s 期望的 char* 不匹配。编译器会警告 "incompatible types"，行为未定义。 附录 D 原文：「应改为 scanf("%s",c);」

高频考点4.3.4 scanf 的其他重要规则

  1. 不能对 scanf 使用精度：scanf("%7.2f", &a); ❌ 非法。 宽度可以（%4d），精度不可以。
  2. 数据间隔：格式串中无非格式字符时，可用空格、TAB、回车分隔； 格式串中有非格式字符时，输入时也必须原样输入该字符。 c scanf("%d,%d", &a, &b); // 必须输入：3,4 ✔ scanf("%d,%d", &a, &b); // 输入 3 4 ✘ 逗号不匹配 scanf("a=%d,b=%d",&a,&b); // 必须输入：a=3,b=4
  3. 数据结束的判定：① 遇到空格、回车、TAB；② 满足宽度要求；③ 遇到非法字符。
  4. \n 不能用于输入：scanf("%d\n",&a); ❌ —— 格式串里的 \n 要求输入一个换行符。 正确写法：scanf("%d ", &a);（尾部空格用于吃掉残留换行）。
  5. scanf 读字符串会截断：char s[5]; scanf("%s", s); 输入 abcdefgh → 越界！ 应写 scanf("%4s", s); 限制宽度。

高频考点4.3.5 printf 的修饰符语法

通用模板：

TXT
% [标志][宽度][.精度]类型字母示例： %-8.2f

标志（printf）

符号 作用 示例

0 宽度不足时用 0 填充 %05d → 00042

宽度 %6d：最少输出字符个数。内容超过宽度会自动扩展，不会截断。

精度 .n（高频考点）

写法 printf 效果
%.2f 浮点数保留 2 位小数
%.5s 字符串最多输出 5 个字符

辨析延伸 宽度 vs 精度：%8.2f = 至少 8 字符宽（不足补空格，右对齐）、保留 2 位小数。 %8.2f 输出 3.14（共 8 字符）。

动态宽度与精度（第 4 次实验重点）⭐

写法 含义
%*d * 表示宽度，由后续实参提供
%*.*f 第一个 * = 总宽度，第二个 * = 小数位数
C

高频考点%*d 与 %-*d：用变量指定宽度的对齐输出

%*d 中的 * 代表宽度由后面的变量指定：printf("%*d", len1, n); 中第一个实参 len1 是宽度，第二个实参 n 才是要输出的数。

  • %*d → 右对齐（默认），占 len1 个字符宽度，数字靠右，前面补空格：
C
printf("%*d", 7, 7);    // 占7格，输出："      7"（前面6个空格）
  • %-*d → 加 - 标志变左对齐，占 len1 个字符宽度，数字靠左，后面补空格：
C
printf("%-*d", 7, 7);   // 占7格，输出："7      "（后面6个空格）

辨析延伸 记忆法：* 吃掉格式串后面的第一个实参当宽度，真正要输出的数往后顺延一位；- 只管对齐方向（左），补空格方向随之相反。

高频考点4.3.6 %f 与 %g 的区别（第 4 次实验明确要求）

%f %g
3.14 3.140000 3.14
0.00001 0.000010 1e-05
1234567.0 1234567.000000 1.23457e+06
123456.0 123456.000000 123456

%g 规则： 1. 按 %e 或 %f 中输出长度较短的方式输出； 2. 仅当指数 < −4 或 ≥ 精度参数（默认 6） 时才用 %e； 3. 选定格式后，尾部的 0 被缩减； 4. 缩减后，小数点后面有 1 个或多个数字时才显示小数点。

高频考点4.3.7 进制输出的前缀问题

%o 输出八进制、%x 输出十六进制，都不会自带前缀 0 / 0x，需要手动拼接：

C
printf("0x%x", num);    // 手动打印 0x 前缀printf("%#x", num);     // C 的标准做法，# 标志自动加前缀（gcc 支持）

高频考点4.8 %.nf 的四舍五入：4 舍 6 入 5 成双（实验五补充）

printf 的 %.nf 舍入与数学课的「四舍五入」不一样，它遵循 4 舍 6 入 5 成双（银行家舍入）：

  1. 待约位 ≤ 4 → 舍去不进位；
  2. 待约位 ≥ 6 → 进位；
  3. 待约位 = 5 → 分两种情况： - 5 后面没有有效数字：看 5 前面一位——偶数不进、奇数进位（0 算偶数）； - 5 后面有非零有效数字：一律进位。
C
printf("%.0f\n", 2.5);   /* → 2   （5 前面是 2，偶数不进） */printf("%.0f\n", 3.5);   /* → 4   （5 前面是 3，奇数进位） */printf("%.1f\n", 0.25);  /* → 0.2 */

⚠️ 实际输出可能「不按规则」：浮点数按 IEEE 754 二进制存储，很多十进制小数（如 0.35）在内存里是略小/略大一点的近似值，5 的判定对象其实是那个近似值。遇到"明明该进位却没进"，先想想内存里的真值。
