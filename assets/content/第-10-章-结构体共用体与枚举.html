第 10 章　结构体、共用体与枚举

高频考点10.1 结构体的定义

C
struct student{    int   num;    char  name[20];    char  sex;    float score;};

高频考点 注意分号：结构体定义末尾必须有分号 ;！漏掉会引发一连串莫名其妙的编译错误。

10.2 结构体变量的定义与初始化

C
/* ① 先定义类型再定义变量 */struct student stu1;​/* ② 定义类型的同时定义变量 */struct student { int num; } stu1, stu2;​/* ③ 定义类型的同时定义变量并初始化（按成员顺序，逗号分隔） */struct student stu1 = {102, "Zhang ping", 'M', 78.5};​/* ④ 结构体数组 */struct student stu[] = {    {101, "Li ping",   'M', 45},    {102, "Zhang ping",'M', 62.5},    {103, "He fang",   'F', 92.5}};/* 元素个数可由编译器推断：sizeof(stu)/sizeof(struct student) */

高频考点 初始化规则： - 未指定的成员自动置 0（'\0' / 0.0）； - 字符数组成员可以用字符串直接初始化：char name[20] → "Zhang ping"； - 字符指针成员也可用字符串：char *name; → "Zhang ping"（⚠️ 指向字符串常量）。

高频考点10.3 结构体成员访问

三种等价写法（教材 lt10-04.c / lt10-06.c 完整演示）：

C
struct student { int num; char name[20]; char sex; float score; } stu1 = {...}, *pstu;pstu = &stu1;​/* 写法一：结构体变量 + 点号 */printf("%d\n", stu1.num);​/* 写法二：结构体指针 + 箭头等价的 (*).  */printf("%d\n", (*pstu).num);​/* 写法三：结构体指针 + 箭头运算符 ->  ★推荐 */printf("%d\n", pstu->num);

高频考点 记忆口诀： - . 用于结构体变量（或结构体数组元素 stu[i].name） - -> 用于结构体指针 - pstu->num 完全等价于 (*pstu).num

易错点 易错点 39：pstu.num 是语法错误（指针不能用点号）；stu1->num 也是语法错误（变量不能用箭头）。

辨析延伸 结构体数组遍历（教材 lt10-07.c）：

C
for (ps = stu; ps < stu + 5; ps++)    printf("%d\t%s\t%c\t%f\n", ps->num, ps->name, ps->sex, ps->score);/* "5" 可改为 sizeof(stu)/sizeof(struct student) */

高频考点10.4 结构体赋值与比较

C
struct student stu1 = {...}, stu2;stu2 = stu1;        /* ✔ 整体赋值：逐成员拷贝（数组也完整拷贝） */

易错点 易错点 40：结构体不能用 == 比较！

C
if (stu1 == stu2) { }   // ❌ 语法错误
必须逐成员比较，或用 memcmp。

高频考点 指针比较是可以的：if (p1 == p2) 比较地址。

高频考点10.5 共用体（union）

C
union u1{    int   i;    /* 4 字节 */    float f;    /* 4 字节 */} u1;​u1.f = (float)120.5;printf("%d %o %x\n", u1.i, u1.i, u1.i);/* 输出的是把 120.5 的 float 位模式按 int 解读的结果 */
  • 共用体的所有成员共享同一块内存；
  • 内存大小 = 最大成员的大小；
  • 同一时刻只有一个成员的值有效；
  • 赋值一个成员会覆盖其他成员。

辨析延伸 教材 lt03-09.c 演示了 union 的"类型双关"技巧； lt10-12.c 演示了 结构体中嵌套共用体。

高频考点10.6 枚举（enum）

C
enum weekday { sun, mon, tue, wed, thu, fri, sat } a, b, c;a = sun;  b = mon;  c = tue;printf("%d,%d,%d\n", a, b, c);   /* 0,1,2 */

规则：

  • 枚举成员的值默认从 0 开始，依次 +1；
  • 可以显式指定：enum { one=1, two=2, three=10, four }; → four = 11；
  • 枚举变量本质是 int，可以参与算术、可以用 switch 匹配。

高频考点 枚举数组的经典应用（教材 lt10-14.c）：计算某月每天是星期几。

C
enum body { one, two, three, four, five, six, seven } month[31], j;j = (enum body)((i-1) % 7);for (i = 1; i <= 30; i++) {    month[i] = j++;    if (j > seven) j = one;      /* 超出最后一个枚举值就回到第一个 */}

高频考点10.7 typedef 类型别名

C
typedef struct yyyymmdd {    int year;    int month;    int day;} YMD;​YMD date;                    /* 等价于 struct yyyymmdd date */scanf("%d-%d-%d", &date.year, &date.month, &date.day);

辨析延伸 教材 lt10-17.c 用 typedef 定义了 YMD 简写，使代码更清晰。 ⚠️ typedef 只是起别名，不创建新类型，不能写 typedef int A; typedef B A;（C 中非法）。

高频考点10.8 动态内存分配

C
#include <stdio.h>#include <stdlib.h>   /* 或 <malloc.h> */​/* 申请 */struct student *ps;ps = (struct student *)malloc(sizeof(struct student));if (ps == NULL) { /* 处理失败 */ }​/* 使用 */ps->num = 102;ps->name = "Zhang ping";   /* ⚠️ 见下方易错点 */​/* 释放 */free(ps);ps = NULL;   /* ✔ 好习惯：释放后置空，避免悬空指针 */

易错点 易错点 41（教材 lt10-09.c 明确演示）：

C
char a[10], *p = a;p = (char *)malloc(10);   /* p 指向申请的区域 */p = "Hello";              /* ❌ 覆盖了指针！原 malloc 区域泄漏 + 变成字符串常量 */printf("%s\n", p);free(p);                  /* ❌ 释放的不是 malloc 分配的内存 → 运行出错 */
正确写法：
C
p = (char *)malloc(10);strcpy(p, "Hello");       /* 用 strcpy，不要直接赋值 */printf("%s\n", p);free(p);

易错点 易错点 42：free(p) 之后必须 p = NULL;，否则 p 成为悬空指针。

辨析延伸 教材 lt10-11.c 演示了用链表保存动态分配的数据（struct student *next;）。

10.9 结构体与链表案例

结构体的价值在「把一条记录当一个整体」：排序时整块赋值、传参时一次传完。下面三段取自黑马教材第 9 章，从数组排序到链表操作，再到一个绕不开的日期计算题。

案例10.9.1 案例 1 · typedef + 结构体数组排序

问题：三名学生的学号、姓名、成绩存在结构体数组里，按成绩从高到低排序输出。

思路：typedef struct {...} Stu; 起个别名，后面写 Stu a[3] 就省掉了 struct 关键字。交换时直接用结构体整体赋值 t = a[j];，不需要逐个成员拷。

Cstu_sort.c
#include <stdio.h>​typedef struct{    int no;    char name[12];    int score;} Stu;​int main(void){    Stu a[3] = {{1, "Tom", 78}, {2, "Amy", 95}, {3, "Bob", 86}};    Stu t;    int i, j;​    for (i = 0; i < 2; i++)                    /* 冒泡，外层跑 n-1 趟 */        for (j = 0; j < 2 - i; j++)            if (a[j].score < a[j + 1].score)            {                t = a[j];                      /* 结构体整体赋值，一次搬完 */                a[j] = a[j + 1];                a[j + 1] = t;            }​    for (i = 0; i < 3; i++)        printf("%d %s %d\n", a[i].no, a[i].name, a[i].score);    return 0;}
▶输入 / 输出示例无需输入 · 输出 3 行
输出 stdout
2 Amy 95
3 Bob 86
1 Tom 78

要点：① 结构体可以整体赋值但不能用 == 比较；② typedef 后面跟的是「类型别名」，写 typedef struct {...} Stu; 时 Stu 是类型名，可以直接 Stu s;，不用再写 struct Stu；③ 排序关键字换成 strcmp(a[j].name, a[j+1].name) > 0 就变成按姓名排。

案例10.9.2 案例 2 · 单向链表的建立、遍历与删除

问题：用尾插法建立 5 个结点的链表（值为 10、20、30、40、50），遍历输出；再删除指定值的结点，再输出。

思路：链表 = 数据域 + 指针域。删除的关键是记住前驱：找到目标后让 pre->next = p->next 把结点「摘」下来，再 free；若要删的是头结点，得改头指针并返回新头。

Clist.c
#include <stdio.h>#include <stdlib.h>​typedef struct Node{    int data;    struct Node *next;             /* 必须写 struct Node *，此时别名还没生效 */} Node;​Node *create(int n){    Node *head = NULL, *tail = NULL, *p;    int i;​    for (i = 1; i <= n; i++)    {        p = (Node *)malloc(sizeof(Node));        p->data = i * 10;        p->next = NULL;        if (head == NULL)            head = tail = p;       /* 第一个结点既是头也是尾 */        else        {            tail->next = p;        /* 接到表尾后面 */            tail = p;        }    }    return head;}​void show(Node *h){    while (h != NULL)    {        printf("%d ", h->data);        h = h->next;    }    printf("\n");}​Node *del(Node *h, int x){    Node *p = h, *pre = NULL;​    while (p != NULL && p->data != x)    {        pre = p;        p = p->next;    }    if (p == NULL)        return h;                  /* 没找到 */    if (pre == NULL)        h = p->next;               /* 删的是头结点 */    else        pre->next = p->next;       /* 摘链 */    free(p);    return h;}​int main(void){    Node *h = create(5);​    show(h);    h = del(h, 30);    show(h);    h = del(h, 10);    show(h);    return 0;}
▶输入 / 输出示例无需输入 · 输出 3 行
输出 stdout
10 20 30 40 50 
10 20 40 50 
20 40 50

要点：① 结构体里自引用必须写 struct Node *next，写 Node *next 在 typedef 还没完成时编不过；② 删除后一定把新头指针接回来（h = del(h, 10);），否则删头结点后就丢了整条链；③ 遍历时 h = h->next 会改掉头指针，函数传的是副本所以 main 里不受影响——这正是「值传递」的好处。

案例10.9.3 案例 3 · 打鱼还是晒网（日期差 + 周期）

问题：某人从 2010 年 1 月 1 日起「三天打鱼、两天晒网」，问某年某月某日他在干什么。

思路：算出目标日距 2010-01-01 的天数 d，周期是 5，所以看 d % 5：0、1、2 打鱼，3、4 晒网。算天数要用到「闰年 366 天」和「每月天数表」。

Cfishing.c
#include <stdio.h>​int isLeap(int y){    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);}​int dayOfYear(int y, int m, int d)     /* 这一天是当年的第几天 */{    int md[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};    int i, sum = 0;​    for (i = 0; i < m - 1; i++)        sum += md[i];    sum += d;    if (m > 2 && isLeap(y))        sum++;                          /* 闰年 2 月多一天 */    return sum;}​int main(void){    int y = 2026, m = 11, d = 20;    int sy = 2010, i, total = 0;​    for (i = sy; i < y; i++)            /* 整年累加 */        total += isLeap(i) ? 366 : 365;​    total += dayOfYear(y, m, d) - 1;    /* 再加本年已过的天数（1 月 1 日算第 0 天） */​    printf("距 2010-01-01 已过 %d 天\n", total);    printf("周期第 %d 天 → %s\n", total % 5 + 1,           (total % 5) < 3 ? "打鱼" : "晒网");    return 0;}
▶输入 / 输出示例无需输入 · 输出 2 行
输出 stdout
距 2010-01-01 已过 6167 天
周期第 3 天 → 打鱼

要点：① 闰年判断口诀「四年一闰、百年不闰、四百年再闰」，三个条件缺一不可；② 天数差是「经过了几天」而不是「第几天」，两者差 1，最容易在这里出错；③ 周期题一律先算 % 周期，再对照规律表——和「今天星期三，100 天后星期几」是同一类题。
