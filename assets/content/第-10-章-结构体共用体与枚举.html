第 10 章　结构体、共用体与枚举

高频考点10.1 结构体的定义

C
struct student{    int   num;    char  name[20];    char  sex;    float score;};

高频考点 注意分号：结构体定义末尾必须有分号 ;！漏掉会引发一连串莫名其妙的编译错误。

10.2 结构体变量的定义与初始化

C
/* ① 先定义类型再定义变量 */struct student stu1;​/* ② 定义类型的同时定义变量 */struct student { int num; } stu1, stu2;​/* ③ 定义类型的同时定义变量并初始化（按成员顺序，逗号分隔） */struct student stu1 = {102, "Zhang ping", 'M', 78.5};​/* ④ 结构体数组 */struct student stu[] = {    {101, "Li ping",   'M', 45},    {102, "Zhang ping",'M', 62.5},    {103, "He fang",   'F', 92.5}};/* 元素个数可由编译器推断：sizeof(stu)/sizeof(struct student) */

高频考点 初始化规则： - 未指定的成员自动置 0（'\0' / 0.0）； - 字符数组成员可以用字符串直接初始化：char name[20] → "Zhang ping"； - 字符指针成员也可用字符串：char *name; → "Zhang ping"（⚠️ 指向字符串常量）。

高频考点10.3 结构体成员访问

三种等价写法（教材 lt10-04.c / lt10-06.c 完整演示）：

C
struct student { int num; char name[20]; char sex; float score; } stu1 = {...}, *pstu;pstu = &stu1;​/* 写法一：结构体变量 + 点号 */printf("%d\n", stu1.num);​/* 写法二：结构体指针 + 箭头等价的 (*).  */printf("%d\n", (*pstu).num);​/* 写法三：结构体指针 + 箭头运算符 ->  ★推荐 */printf("%d\n", pstu->num);

高频考点 记忆口诀： - . 用于结构体变量（或结构体数组元素 stu[i].name） - -> 用于结构体指针 - pstu->num 完全等价于 (*pstu).num

易错点 易错点 39：pstu.num 是语法错误（指针不能用点号）；stu1->num 也是语法错误（变量不能用箭头）。

辨析延伸 结构体数组遍历（教材 lt10-07.c）：

C
for (ps = stu; ps < stu + 5; ps++)    printf("%d\t%s\t%c\t%f\n", ps->num, ps->name, ps->sex, ps->score);/* "5" 可改为 sizeof(stu)/sizeof(struct student) */

高频考点10.4 结构体赋值与比较

C
struct student stu1 = {...}, stu2;stu2 = stu1;        /* ✔ 整体赋值：逐成员拷贝（数组也完整拷贝） */

易错点 易错点 40：结构体不能用 == 比较！

C
if (stu1 == stu2) { }   // ❌ 语法错误
必须逐成员比较，或用 memcmp。

高频考点 指针比较是可以的：if (p1 == p2) 比较地址。

高频考点10.5 共用体（union）

C
union u1{    int   i;    /* 4 字节 */    float f;    /* 4 字节 */} u1;​u1.f = (float)120.5;printf("%d %o %x\n", u1.i, u1.i, u1.i);/* 输出的是把 120.5 的 float 位模式按 int 解读的结果 */
  • 共用体的所有成员共享同一块内存；
  • 内存大小 = 最大成员的大小；
  • 同一时刻只有一个成员的值有效；
  • 赋值一个成员会覆盖其他成员。

辨析延伸 教材 lt03-09.c 演示了 union 的"类型双关"技巧； lt10-12.c 演示了 结构体中嵌套共用体。

高频考点10.6 枚举（enum）

C
enum weekday { sun, mon, tue, wed, thu, fri, sat } a, b, c;a = sun;  b = mon;  c = tue;printf("%d,%d,%d\n", a, b, c);   /* 0,1,2 */

规则：

  • 枚举成员的值默认从 0 开始，依次 +1；
  • 可以显式指定：enum { one=1, two=2, three=10, four }; → four = 11；
  • 枚举变量本质是 int，可以参与算术、可以用 switch 匹配。

高频考点 枚举数组的经典应用（教材 lt10-14.c）：计算某月每天是星期几。

C
enum body { one, two, three, four, five, six, seven } month[31], j;j = (enum body)((i-1) % 7);for (i = 1; i <= 30; i++) {    month[i] = j++;    if (j > seven) j = one;      /* 超出最后一个枚举值就回到第一个 */}

高频考点10.7 typedef 类型别名

C
typedef struct yyyymmdd {    int year;    int month;    int day;} YMD;​YMD date;                    /* 等价于 struct yyyymmdd date */scanf("%d-%d-%d", &date.year, &date.month, &date.day);

辨析延伸 教材 lt10-17.c 用 typedef 定义了 YMD 简写，使代码更清晰。 ⚠️ typedef 只是起别名，不创建新类型，不能写 typedef int A; typedef B A;（C 中非法）。

高频考点10.8 动态内存分配

C
#include <stdio.h>#include <stdlib.h>   /* 或 <malloc.h> */​/* 申请 */struct student *ps;ps = (struct student *)malloc(sizeof(struct student));if (ps == NULL) { /* 处理失败 */ }​/* 使用 */ps->num = 102;ps->name = "Zhang ping";   /* ⚠️ 见下方易错点 */​/* 释放 */free(ps);ps = NULL;   /* ✔ 好习惯：释放后置空，避免悬空指针 */

易错点 易错点 41（教材 lt10-09.c 明确演示）：

C
char a[10], *p = a;p = (char *)malloc(10);   /* p 指向申请的区域 */p = "Hello";              /* ❌ 覆盖了指针！原 malloc 区域泄漏 + 变成字符串常量 */printf("%s\n", p);free(p);                  /* ❌ 释放的不是 malloc 分配的内存 → 运行出错 */
正确写法：
C
p = (char *)malloc(10);strcpy(p, "Hello");       /* 用 strcpy，不要直接赋值 */printf("%s\n", p);free(p);

易错点 易错点 42：free(p) 之后必须 p = NULL;，否则 p 成为悬空指针。

辨析延伸 教材 lt10-11.c 演示了用链表保存动态分配的数据（struct student *next;）。
