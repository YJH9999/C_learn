高频考点D.2 数学函数（附录 F.4）

函数 功能 头文件 注意
sqrt(x) 平方根 √x <math.h> x ≥ 0；GCC 需 -lm
pow(x, y) 幂 x^y <math.h> 返回 double
fabs(x) 绝对值（double） <math.h> 判断浮点是否接近 0 用它
fabsf(x) 绝对值（float） <math.h> 与 float 精度配套
fabsl(x) 绝对值（long double） <math.h>
exp(x) e^x <math.h>
log(x) 自然对数 ln x <math.h> x > 0
log10(x) 常用对数 lg x <math.h> x > 0
sin/cos/tan(x) 三角函数 <math.h> 单位是弧度，不是角度
asin/acos/atan(x) 反三角函数 <math.h> 返回弧度
atan2(y, x) y/x 的反正切 <math.h> 能正确处理象限，推荐
ceil(x) 向上取整 <math.h> 3.2 → 4.0
floor(x) 向下取整 <math.h> 3.8 → 3.0
fmod(x, y) 求余（浮点） <math.h> 浮点版的 %
abs(i) 整数绝对值 <stdlib.h> 不是 <math.h>
labs(n) long 绝对值 <stdlib.h>
hypot(x,y) 斜边长 √(x²+y²) <math.h>

高频考点 三角函数必背：弧度制！sin(30) 不是 0.5，sin(30 * 3.14159 / 180) 才是。 头文件：数学函数在 <math.h>，不是 <stdlib.h>（abs 在 stdlib）。

高频考点D.4 随机数

C
#include <stdlib.h>#include <time.h>​srand((unsigned)time(NULL));    /* 用时间作为种子，只调用一次！ */for (i = 0; i < N; i++)    a[i] = rand() % 100;        /* 生成 0~99 的随机数 */

高频考点 关键： 1. srand() 每次循环前调用会得到相同序列（种子相同 → 序列相同）； 2. rand() 返回 0 ~ RAND_MAX 的整数； 3. rand() % m 生成 0 ~ m-1； 4. rand() % (b-a+1) + a 生成 a ~ b 的闭区间。

教材 lt07-01.c / lt07-06.c / lt07-29.c 都是这个模式。

高频考点D.5 时间函数

C
#include <time.h>​time_t t = time(NULL);                  /* 当前时间戳 */struct tm *p = localtime(&t);          /* 转换为结构体 */printf("%d-%02d-%02d %02d:%02d:%02d\n",       p->tm_year + 1900,               /* ⚠️ 年份要 +1900！ */       p->tm_mon + 1,                   /* ⚠️ 月份要 +1！ */       p->tm_mday, p->tm_hour, p->tm_min, p->tm_sec);

高频考点 高频陷阱：tm_year 是"从 1900 开始算的年数"（2026 年是 126），tm_mon 是"从 0 开始算的月份"（1 月是 0）。 不加上偏移量就会输出 1900 年的时间。
