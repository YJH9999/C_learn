导学 01　C 语言简介

🧭 路线对照：本节对应详解 —— 第 1 章「C 语言概述」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

1.1 起源

C 语言由 丹尼斯·里奇（Dennis Ritchie） 于 1972 年在贝尔实验室设计开发，最初目的是为了移植和开发 UNIX 操作系统。C 语言以 B 语言为基础演化而来，凭借其简洁的语法、接近硬件的控制能力和出色的运行效率，成为系统编程领域最重要的语言之一。

1.2 主要特点

特点 说明
语法简洁 关键字少，易于学习和掌握
结构化编程 支持函数、模块化设计，逻辑清晰
高效性 编译后生成接近汇编语言的机器代码，运行速度快
底层控制 可直接操作内存和硬件
可移植性强 可在多种平台上编译运行
标准库丰富 生态成熟，社区庞大

1.3 典型应用场景

  • 操作系统内核（Linux、Windows NT）
  • 编译器与解释器（GCC、CPython）
  • 嵌入式系统与单片机开发
  • 数据库系统（MySQL、SQLite）
  • 游戏引擎底层与图形渲染库

2.1 需要的工具

编写 C 程序需要两样东西：文本编辑器 和 C 编译器。

2.2 文本编辑器推荐

编辑器 说明
VS Code 推荐。轻量、插件丰富，安装 C/C++ 扩展即可使用
Dev-C++ 经典 C/C++ IDE，开箱即用
Sublime Text 轻量快速，可定制性强

2.3 编译器安装

Windows

推荐安装 MinGW-w64，提供 Windows 下的 GCC 工具链：

  1. 访问 MinGW-w64 下载页
  2. 下载对应版本（64 位系统选 x86_64）
  3. 解压后将 bin 目录添加到系统 PATH 环境变量
  4. 在命令行输入 gcc -v 验证安装

Linux / macOS

  • Linux：终端输入 gcc -v 检查，未安装则执行 sudo apt install gcc
  • macOS：安装 Xcode 开发工具即可获得 GCC

2.4 编译与运行

BASH
gcc hello.c -o hello    # 编译源文件，生成可执行文件./hello                  # 运行（Linux/macOS）hello.exe                # 运行（Windows）

多文件编译：当项目包含多个 .c 文件时，需要一起编译：

BASH
gcc file1.c file2.c -o output.exe

4.1 令牌（Token）

C 程序由各种令牌组成，令牌可以是关键字、标识符、常量、字符串值或符号。

C

上述语句包含 5 个令牌：printf ( "Hello, World! \n" ) ;

4.2 分号

在 C 程序中，分号 ; 是语句结束符。每个语句必须以分号结尾。

4.3 注释

C
// 单行注释​/*   多行注释   可以跨越多行*/

注释会被编译器忽略，不会影响程序执行。

4.4 标识符

标识符用于标识变量、函数或任何其他用户自定义项目的名称。命名规则：

  • 由字母、数字和下划线组成
  • 必须以字母或下划线开头
  • 区分大小写（age 和 Age 是不同的标识符）

7.3 转义字符

转义字符 含义

\\ 反斜杠 \
\' 单引号 '

导学 12　作用域与存储类

🧭 路线对照：本节对应详解 —— 第 8 章「函数」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

12.1 变量作用域

作用域 说明
局部变量 在函数或代码块内部定义，仅在该范围内有效
全局变量 在所有函数外部定义，整个文件中均可访问
形式参数 函数参数，作为局部变量在函数内使用

当局部变量和全局变量同名时，局部变量优先。

12.2 存储类

存储类定义变量的存储位置、生命周期和作用域。

auto（自动存储类）

局部变量的默认存储类，在函数开始时创建，函数结束时销毁。

C
{    int a;           // 等价于 auto int a;    auto int b;}

register（寄存器存储类）

建议编译器将变量存储在寄存器中以提高访问速度（只是建议，编译器可能不采纳）。不能对 register 变量使用 & 取地址。

C
{    register int counter;    // 建议存储在寄存器中}

static（静态存储类）

static 修饰不同变量时的效果：

修饰对象 效果
局部变量 生命周期延长到整个程序运行期间；只在第一次调用时初始化；后续调用保持上次的值；存储在数据段
全局变量 限制作用域为当前文件（文件作用域），其他文件无法访问
函数 限制函数为文件作用域，只能在当前文件中被调用

static 修饰的变量若未初始化，会被自动初始化为 0。

示例

C
#include <stdio.h>​void func(void){    static int count = 0;    // 只初始化一次    count++;    printf("count = %d\n", count);}​int main(){    func();    // count = 1    func();    // count = 2    func();    // count = 3    return 0;}

extern（外部存储类）

用于声明在其他文件中定义的全局变量或函数，使当前文件可以访问。

C
// 文件1: file1.cint count = 5;       // 定义全局变量​// 文件2: file2.cextern int count;    // 声明：count 在 file1.c 中定义// 现在可以使用 count​// 编译: gcc file1.c file2.c -o output

🧭 路线对照：本节对应详解 —— 第 7 章「数组与字符串」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

13.1 一维数组

声明与初始化

C
int arr[10];                              // 声明int nums[5] = {1, 2, 3, 4, 5};           // 声明并初始化int nums[] = {1, 2, 3, 4, 5};             // 省略大小，自动推断为 5int arr[5] = {0};                         // 全部初始化为 0

数组元素在内存中连续存储，第一个元素的索引为 0。

访问数组元素

C
int nums[5] = {10, 20, 30, 40, 50};printf("%d", nums[0]);    // 输出 10（第一个元素）printf("%d", nums[4]);    // 输出 50（最后一个元素）nums[2] = 100;            // 修改第三个元素

遍历数组

C
int nums[5] = {10, 20, 30, 40, 50};int length = sizeof(nums) / sizeof(nums[0]);​for (int i = 0; i < length; i++) {    printf("nums[%d] = %d\n", i, nums[i]);}

13.2 二维数组

C
int matrix[3][4];    // 3行4列​// 初始化int matrix[2][3] = {    {1, 2, 3},    {4, 5, 6}};​// 访问matrix[0][1] = 10;   // 第1行第2列

遍历二维数组

C
for (int i = 0; i < 2; i++) {    for (int j = 0; j < 3; j++) {        printf("%d ", matrix[i][j]);    }    printf("\n");}

13.3 数组与指针

数组名本身就是一个指向数组首元素的常量指针：

C
int arr[5] = {10, 20, 30, 40, 50};int *ptr = arr;        // 等价于 int *ptr = &arr[0];​printf("%d", *ptr);       // 10printf("%d", *(ptr+1));   // 20printf("%d", arr[0]);     // 10

数组名是常量指针，不能被重新赋值（arr = ptr 是错误的）。

导学 14　字符串

🧭 路线对照：本节对应详解 —— 第 7 章「数组与字符串」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

14.1 字符串的定义

C 语言中，字符串实际上是使用空字符 \0 结尾的一维字符数组。

C
char str1[7] = {'H', 'e', 'l', 'l', 'o', '!', '\0'};  // 显式添加 \0char str2[] = "Hello!";    // 编译器自动在末尾添加 \0

注意："Hello!" 的长度是 6，但字符数组大小为 7（包含 \0）。

14.2 常用字符串函数

使用这些函数需要引入 <string.h> 头文件：

函数 说明
strlen(s) 返回字符串长度（不含 \0）
strcpy(s1, s2) 将 s2 复制到 s1
strcat(s1, s2) 将 s2 连接到 s1 末尾
strcmp(s1, s2) 比较字符串，相等返回 0
strchr(s, ch) 返回 s 中首次出现 ch 的指针
strstr(s1, s2) 返回 s1 中首次出现 s2 的指针

示例

C
#include <stdio.h>#include <string.h>​int main(){    char str1[20] = "Hello";    char str2[20] = "World";​    printf("strlen(str1): %lu\n", strlen(str1));     // 5​    char str3[20];    strcpy(str3, str1);    printf("strcpy: %s\n", str3);                     // Hello​    strcat(str1, str2);    printf("strcat: %s\n", str1);                     // HelloWorld​    printf("strcmp: %d\n", strcmp("abc", "abc"));     // 0    return 0;}

导学 15　指针

🧭 路线对照：本节对应详解 —— 第 9 章「指针」重难点。先在本节建立直觉，再到详解章深挖易错点与高频考点。

15.1 什么是指针

指针也就是内存地址。指针变量是用来存放内存地址的变量。

每一个变量都有一个内存位置，可以使用 & 运算符获取其地址。

15.2 指针的声明与使用

C
int var = 20;      // 定义普通变量int *ptr;           // 定义指针变量ptr = &var;         // 将 var 的地址赋给 ptr​printf("var 的地址: %p\n", ptr);     // 输出地址printf("*ptr 的值: %d\n", *ptr);     // 输出 20（解引用）

关键运算符

运算符 说明
& 取地址：获取变量的内存地址
* 解引用：访问指针指向地址的值

15.3 指针的类型

C
int    *ip;     // 整型指针double *dp;     // double 型指针float  *fp;     // float 型指针char   *ch;     // 字符型指针

不同类型的指针本质上存储的都是相同格式的地址，区别在于它们指向的数据类型不同，决定了指针运算时的步长。

15.4 连续声明指针变量

定义多个指针变量时，每个变量前都需要加 *：

C
int *p1, *p2, *p3;     // 三个都是指针变量int *p4, p5;           // p4 是指针，p5 是普通 int 变量

15.5 NULL 指针

声明指针时如果没有确切的地址赋值，应赋值为 NULL：

C
int *ptr = NULL;    // 空指针，地址为 0​if (ptr) {    // ptr 非空}if (!ptr) {    // ptr 为空}

使用未初始化的指针（野指针）是危险的行为，可能导致程序崩溃。

15.6 指针的大小

指针的大小取决于系统位数，与指向的数据类型无关：

  • 32 位系统：指针占 4 字节
  • 64 位系统：指针占 8 字节
C
printf("%zu", sizeof(int*));    // 64 位系统输出 8

15.7 指针与数组

C
int arr[5] = {10, 20, 30, 40, 50};int *ptr = arr;​for (int i = 0; i < 5; i++) {    printf("%d ", *(ptr + i));    // 通过指针遍历数组}// 输出: 10 20 30 40 50

15.8 指针作为函数参数

C
// 通过指针修改实参的值void increment(int *n){    (*n)++;}​int main(){    int num = 5;    increment(&num);    printf("%d", num);    // 输出 6    return 0;}

导学 16　枚举

🧭 路线对照：本节对应详解 —— 第 10 章「结构体、共用体与枚举」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

16.1 定义枚举

枚举用于定义一组具有离散值的常量，使代码更简洁易读。

C
enum 枚举名 { 枚举元素1, 枚举元素2, ... };

示例

C
enum DAY{    MON = 1, TUE, WED, THU, FRI, SAT, SUN};

第一个枚举成员默认值为 0，后续成员依次加 1。指定值后，后续成员从该值开始递增。

16.2 定义枚举变量

C
// 方式一：先定义类型，再定义变量enum DAY { MON=1, TUE, WED, THU, FRI, SAT, SUN };enum DAY day;​// 方式二：定义类型的同时定义变量enum DAY { MON=1, TUE, WED, THU, FRI, SAT, SUN } day;​// 方式三：省略枚举名enum { MON=1, TUE, WED, THU, FRI, SAT, SUN } day;

16.3 使用示例

C
#include <stdio.h>​enum DAY { MON=1, TUE, WED, THU, FRI, SAT, SUN };​int main(){    enum DAY day = WED;    printf("%d\n", day);    // 输出 3​    // 遍历枚举    for (day = MON; day <= SUN; day++) {        printf("%d ", day);    }    // 输出: 1 2 3 4 5 6 7    return 0;}

16.4 枚举与 switch

C
enum color { RED = 1, GREEN, BLUE };enum color fav = RED;​switch (fav) {    case RED:   printf("红色\n"); break;    case GREEN: printf("绿色\n"); break;    case BLUE:  printf("蓝色\n"); break;}

导学 17　结构体

🧭 路线对照：本节对应详解 —— 第 10 章「结构体、共用体与枚举」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

17.1 定义结构体

结构体允许存储不同类型的数据项，是一种用户自定义的数据类型。

C
struct 结构体名{    成员列表;} 变量列表;

示例

C
struct Books{    char  title[50];    char  author[50];    char  subject[100];    int   book_id;};

17.2 定义结构体变量

C
struct Books book1;         // 方式一：声明后定义变量

17.3 初始化结构体

C
struct Books book = {"C 语言", "RUNOOB", "编程语言", 123456};

17.4 访问结构成员

使用 . 运算符访问结构体成员：

C
#include <stdio.h>#include <string.h>​struct Books{    char  title[50];    char  author[50];    int   book_id;};​int main(){    struct Books book1;​    strcpy(book1.title, "C Programming");    strcpy(book1.author, "Dennis Ritchie");    book1.book_id = 123456;​    printf("标题: %s\n", book1.title);    printf("作者: %s\n", book1.author);    printf("ID: %d\n", book1.book_id);    return 0;}

17.5 结构体作为函数参数

C
void printBook(struct Books book){    printf("标题: %s\n", book.title);    printf("作者: %s\n", book.author);    printf("ID: %d\n", book.book_id);}​// 调用: printBook(book1);

17.6 指向结构体的指针

使用 -> 运算符通过指针访问结构体成员：

C
void printBook(struct Books *book){    printf("标题: %s\n", book->title);    printf("作者: %s\n", book->title);    printf("ID: %d\n", book->book_id);}​// 调用: printBook(&book1);

book->title 等价于 (*book).title。

17.7 typedef 与结构体

使用 typedef 为结构体创建别名，简化书写：

C
typedef struct{    char name[20];    int age;    float height;} Person;​Person p1;    // 无需再写 struct 关键字

17.8 计算结构体大小

C
struct Person {    char name[20];    int age;    float height;};​printf("Person 大小: %zu 字节\n", sizeof(struct Person));

结构体大小可能受到内存对齐规则影响，实际大小可能大于各成员大小之和。

18.3 #define 定义宏

宏是用来完成文本替换的，可以带参数：

C
// 不带参数的宏#define PI 3.14159​// 带参数的宏#define MAX(a, b) ((a) > (b) ? (a) : (b))#define SQUARE(x) ((x) * (x))​int main(){    int a = 10, b = 20;    printf("最大值: %d\n", MAX(a, b));     // 最大值: 20    printf("平方: %d\n", SQUARE(5));         // 平方: 25    return 0;}

导学 20　初学者常见错误

🧭 路线对照：本节对应详解 —— 附录 D「C 语言编程常见错误汇编」。先在本节建立直觉，再到详解章深挖易错点与高频考点。

20.1 scanf 中误加 \n

C
// 错误写法scanf("%d\n", &num);    // \n 要求继续等待输入，程序会卡住​// 正确写法scanf("%d", &num);

scanf 格式串中的 \n 会让程序继续等待新字符，必须再敲一个非空白字符才会放行。删掉 \n 即可。

20.2 新变量未赋值

C
int sum;         // 未初始化，sum 包含垃圾值// 使用前未赋值直接使用 sum 会导致不可预测的结果​// 正确做法int sum = 0;

20.3 代码修改后未重新编译

运行后发现输出与预期不符（"货不对板"），通常是因为：

  1. 修改代码后忘记保存（Ctrl + S）
  2. 未重新编译（Ctrl + Shift + B 或终端编译）
  3. 运行了旧的 .exe 文件

每次修改代码后，务必：保存 → 重新编译 → 运行新程序

20.4 extern 跨文件引用报错

单独编译某个 .c 文件时，编译器看不到其他文件中定义的变量，会报"未定义的引用"错误。

BASH
# 错误：只编译了一个文件gcc file2.c -o output.exe​# 正确：将相关文件一起编译gcc file1.c file2.c -o output.exe

20.5 指针未初始化

C
int *ptr;         // 野指针，指向未知地址*ptr = 100;       // 危险！可能导致程序崩溃​// 正确做法int *ptr = NULL;  // 初始化为空指针// 或int a = 100;int *ptr = &a;    // 指向有效的变量

20.6 数组越界访问

C
int arr[5] = {1, 2, 3, 4, 5};printf("%d", arr[5]);    // 错误！有效索引为 0~4

C 语言不会自动检查数组边界，越界访问会导致未定义行为。

20.7 忘记保存文件

代码修改后如果不保存，编译器编译的是旧代码，无法链接生成新的可执行文件。

养成习惯：每次修改代码后先 Ctrl + S 保存。
