附录 C　逻辑错误与"能跑但错"清单

这一类不产生任何编译错误，但结果完全错误，是实验/考试扣分重灾区。

# 错误代码 问题 修正
1 int a; if (a=5) = 写成 == if (a == 5)
2 if (a <= x <= b) 连续比较 if (a <= x && x <= b)
3 float f; printf("%d", f) 格式符不匹配 printf("%f", f)
4 double d; scanf("%f", &d) float/double 混用 scanf("%lf", &d)
5 int a; printf("%f", a) 整数按浮点解读 printf("%d", a)
6 int max = 0; 求数组最大值 全负数时错 int max = a[0];
7 int sum = a / b;（需小数） 整数除法 sum = (float)a / b;
8 if (x == 0.3) 浮点精度 if (fabs(x - 0.3) < 1e-9)
9 char s[5] = "hello"; 缺结束符空间 char s[6]
10 char s[6] = {'h','e','l','l','o'}; 缺 '\0' 补上 '\0' 或用 printf("%c") 逐个输出
11 scanf("%c", &ch) 读不到预期 %c 吞空格 scanf(" %c", &ch)
12 scanf("%s", &str) 数组名不需 & scanf("%s", str)
13 scanf("%s", s) 数组太小 缓冲区溢出 加大数组 or 用 %ns 限宽
14 if (a%3==0); 多分号 删分号
15 for (i=0;i<5;i++); 多分号 删分号
16 switch 漏 break case 穿透 补 break
17 while 中 continue 跳过 i++ 死循环 把 i++ 提前或改用 for
18 do {...} while(cond); 写成 while 至少执行一次 注意区分
19 a = b / c; 其中 b、c 是 int 整数除法丢小数 强制转换 (double)b / c
20 int *p; *p = 5; 野指针 int *p = &a; 或 = NULL
21 char *p = "abc"; p[0]='X'; 改字符串常量 用 char s[] = "abc";
22 free(p) 后不置 NULL 悬空指针 free(p); p = NULL;
23 结构体用 == 比较 语法错误 逐成员比较
24 struct 定义后漏 ; 连锁语法错误 补分号
25 printf("%5.2f", a) 中 a 是 int 格式错配 先转 (double)a
26 二维数组 a[i][j] 下标写反 结果错位 核对行列含义
27 float avg = sum / n;（sum、n 是 int） 整数除法 avg = (float)sum / n;
28 int a[10] 却 scanf 11 个数 越界 核对数组长度
29 局部变量未初始化就使用 值随机（C4700 警告） 声明时赋初值
30 main 函数写 void main() 不标准 int main(void)
