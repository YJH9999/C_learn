/*​投票操控​【题目描述】​jwkl举办了算法兴趣培养计划，但收到了大量的差评。于是他决定开始操控评论区的投票。​投票的票数记为s，s的初始值为 0。​共有 n 位参与者，每个人都有一个投票阈值ai，n个人将按顺序依次投票，当轮到第 i 个人投票时：​如果 s ≥ ai，他会投出一个赞成票，使 s 增加 1；​如果 s < ai，他会投出一个反对票，使 s 减少 1。​jwkl可以自由安排这 n 个人的投票顺序。他想知道，这次投票的最终票数 s 的可能的最大值是多少。​【输入格式】​输入的第一行包含一个整数n(1≤n≤10^5)，表示投票者的数量。​第二行包含n个整数 a1,a2, ... , an(|ai|≤10^5) ,表示每位投票者的阈值，数值之间用空格分隔。​【输出格式】​输出一行，包含一个整数，表示最终票数s的最大值。​【输入样例】​5​-1 0 1 2 3​【输出样例】​5​【样例说明】​例如，将序列 a 排列为 [0,-1,2,1,3]。初始时 s=0。由于 s≥a1=0，第一个人投出赞成票，s 变为1。​此后其余四人也满足 s≥ai，因此他们都会投出赞成票。最终 s=5，这就是可能的最大结果。​*/​#include <stdio.h>​int main(){    int s = 0;​    int a,n = 0;​    scanf("%d",&n);//得到总数​    int arr[n];​    for(int i=0;i<n;i++){        scanf("%d",&a);​        arr[i]=a;    }​    for(int i=1;i<n;i++){        for(int j=0;j<n-i;j++){            if(arr[j]>arr[j+1]){                int temp=arr[j];​                arr[j]=arr[j+1];​                arr[j+1]=temp;            }        }    }​    for(int i=0;i<n;i++){        if(s>=arr[i]){            s++;        }​        else{            s--;        }    }​    printf("%d",s);​    return 0;}
