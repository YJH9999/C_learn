第 1 章　C 语言概述

1.1 C 语言的基本单位：函数

C 程序由一个或多个函数构成，其中必须有且只有一个 main 函数，程序总是从 main 开始执行、也以 main 返回而结束。

C
#include <stdio.h>      /* 文件包含预处理命令 */​int main(void)          /* 主函数：int 返回值，void 无参数 */{    printf("Hello, World!\n");    return 0;           /* 返回 0 表示正常结束 */}

高频考点1.2 程序从源文件到运行：四个阶段

阶段 中文名 做了什么 产物
编辑 编辑 写 .c 源程序，建立并修改程序 xxx.c
编译 编译 编译器检查语法错误，翻译成目标代码 xxx.obj(Win) / xxx.o(Linux)
连接 链接 目标文件 + 系统库函数合并；此阶段也会报错 xxx.exe
运行 运行 CPU 执行二进制机器码 输出结果

易错点 易错点 1：obj 文件本身是不完整的——它只包含你写的函数，缺少 printf 等库函数的实现。 所以会出现「编译通过但链接失败」：典型原因是① 忘记 #include <stdio.h>；② 调用了不存在的函数名；③ 把 .c 文件的扩展名写成了 .txt 导致没被编译。 高频考点 经典题：「程序运行结果错误，首先应该检查哪个阶段？」→ 答：先看编译阶段是否报语法错，再看连接阶段（链接错误说明函数名写错或头文件缺失）。

1.3 C 语言的特点

  • 源程序是文本文件，需经编译 → 链接才能执行；
  • 只能使用很少的库函数，核心语言功能由标准库提供；
  • 自由度高（指针直接操作内存），但也因此容易出错；
  • 可移植性好：只需重新编译即可在别的平台运行。

1.5 一个标准 C 程序的组成

C
/* 1. 文件包含 */#include <stdio.h>#include <math.h>​/* 2. 宏定义 */#define PI 3.14159​/* 3. 全局变量声明 */double area;​/* 4. 函数原型（声明） */double circle(double r);​/* 5. 自定义函数定义 */double circle(double r){    return PI * r * r;}​/* 6. 主函数 */int main(void){    double r;    scanf("%lf", &r);    area = circle(r);    printf("%f\n", area);    return 0;}

高频考点 填空题高频：main 函数返回值类型是 int；void 表示"无返回值/无参数"。 int main() 与 int main(void) 在旧式 C 中等价，现代 C 推荐 (void)。
