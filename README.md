# C 语言知识库（C Learn）

一个**零依赖、纯静态**的 C 语言知识点大全网站：整合课堂笔记、教材例题、实验知识点与个人练习代码，覆盖基础知识点、易错知识点与重难点，所有数值结论均经 GCC 实机编译验证。

## 内容结构

| 版块       | 内容                                                         |
| ---------- | ------------------------------------------------------------ |
| 第 0 篇    | 总览与速查（知识地图、十大高频陷阱）                         |
| 学习路线篇 | 零基础导学 01–20（默认折叠，点击展开）                       |
| 第 1–4 篇  | 语言基础 / 程序控制 / 数据组织与函数 / 进阶专题（含堆内存与文件进阶） |
| 第 5 篇    | 附录 A–G（关键字、错误速查、库函数、优先级、易错 TOP 60、随机数专题） |
| 实战练习篇 | HM01–HM14：个人练习代码 160+ 题（课后练习、分支应用题、ACM/实验/洛谷/巩固） |

## 站点结构（分章懒加载）

```
C_learn/
├── index.html              # 外壳（约 130KB）：顶栏 / 目录树 / 封面，不含正文
└── assets/
    ├── style.css           # macOS 风格视觉系统
    ├── fonts.css           # 字体声明
    ├── app.js              # 交互（目录折叠、分章加载、搜索、主题、阅读进度）
    ├── manifest.js         # 章节清单：片段顺序 + 锚点 → 片段映射
    ├── search-index.js     # 全文搜索索引（首次搜索时才加载）
    ├── fonts/              # 按文档字符集子集化的 woff2（Inter / Noto Sans SC / JetBrains Mono）
    └── content/            # 正文按章节拆分的 47 个 HTML 片段（约 1.4MB）
        ├── 第-0-篇-总览与速查.html
        ├── 第-9-章-指针.html
        ├── hm-03-循环与经典数值题.html
        └── …
```

- **正文按章节分文件**：`index.html` 只含外壳，跳转到哪章就加载哪章，向下滚动自动续载下一章——想单独修改某个章节，直接编辑 `assets/content/` 里对应文件即可
- 搜索索引构建期预生成（`search-index.js`），运行时按需加载
- 无任何框架与外部依赖，字体已子集化，**深浅色主题跟随系统、可手动切换**
- 阅读进度自动保存（localStorage，按锚点记录）
- **代码不再在浏览器里跑**：每段示例下方直接挂一个可折叠的「输入 / 输出示例」，内容是全站构建时用 GCC 实机编译运行留下的结果，与真实编译器行为一致（含 `\r\n`、保留位数、返回值），比浏览器内的解释器靠谱得多

## 🎯 备考中心

- **题库规模**：理论题 848 道（单选 518 / 判断 94 / 填空 172 / 程序阅读 64）+ 编程题 147 道，每道编程题的样例输入输出都由 GCC 跑出来核对
- **理论复习**：14 章 355 个要点，按「重点 / 高频 / 易错 / 易混 / 偏僻」打标签，标注易错 92 条、偏僻 47 条；左栏可按标签筛选、按关键词搜索（`/` 聚焦），命中处高亮，章节可折叠，滚动时左栏自动跟随
- **组卷**：快速套卷（标准 / 客观 / 阅读 / 小测 / **易错专练** / **江南机考 20+15**）、题型配额 stepper、章节多选、来源筛选，抽题按配额分配，不够时汇总提示；「易错专练」会自动把来源切到「原创 · 易错辨析」，「江南机考」会把章节锁到第 1~5 章（考到分支结构）并按真实卷面配 20 单选 + 15 填空
- **题库总览**：按题库（理论 / 编程）× 题型 × 章节 × 来源 × 关键词筛选，每页 30 条，答案与解析默认折叠
- **编程题**：题干 + 提示 + 参考答案 +「输入 / 输出示例」，可先手写再对照

## 👤 账号与学习数据

- **个人中心**（右上角头像）：昵称、头像（点头像上传图片，首次设置时可挑 emoji / 纯色）、使用时长、做题数、错题数、正确率
- **首次引导**：第一次进入需设置昵称（默认 Student）与头像；先看到「注册 / 登录」卡，可以当场注册或登录、也可以先跳过；跳过后的资料卡底部留了「返回注册」入口，随时能回去登录
- **跨设备同步**：用邮箱 + 密码注册 Supabase 账号（**不再需要 GitHub 令牌**），错题本、收藏、统计、试卷记录、头像昵称都跟着账号走（表上开了行级安全，只本人可读写）。三个站共用同一个账号，换设备登录即自动拉回；未登录时进入备考中心会提示一次
- **试卷记录**：每次组卷自动留档（题目、作答、分数、用时），可继续作答 / 回看卷面 / 重做 / 删除
- **线上 / 离线二选一**：组完卷先选作答方式——线上直接答题自动判分；离线打印卷子手写（空白卷或含答案版都能打），做完拍照或导入 PDF 交回
- **离线时长折算**：上传离线作答后，按该卷考试用时的 60%（按题型估算总时长）一次性计入本站学习时长，同一份卷只计一次
- **离线附件**：记录里带照片 / PDF，图片随账号同步，PDF 超过 700KB 时原件只留在本机
- **导出**：作答记录、错题本、空白卷、含答案卷都能导出为 PDF（浏览器打印 → 另存为）
- **字号加减**：顶栏 A− / A+ 全站缩放 85%–130%，三站共用

## 本地预览

正文通过 `fetch` 分章加载，需通过 HTTP 访问（**直接双击 index.html 无法加载正文**，页面会有提示）：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```
