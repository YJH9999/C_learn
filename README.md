# C 语言知识库（C Learn）

一个**零依赖、纯静态**的 C 语言知识点大全网站：整合课堂笔记、教材例题、实验知识点与个人练习代码，覆盖基础知识点、易错知识点与重难点，所有数值结论均经 GCC 实机编译验证。

## 内容结构

| 版块       | 内容                                                         |
| ---------- | ------------------------------------------------------------ |
| 第 0 篇    | 总览与速查（知识地图、十大高频陷阱）                         |
| 学习路线篇 | 零基础导学 01–20（默认折叠，点击展开）                       |
| 第 1–4 篇  | 语言基础 / 程序控制 / 数据组织与函数 / 进阶专题（含堆内存与文件进阶） |
| 第 5 篇    | 附录 A–G（关键字、错误速查、库函数、优先级、易错 TOP 60、随机数专题） |
| 实战练习篇 | HM01–HM14：个人练习代码 160+ 题（课后练习、分支应用题、ACM/实验/洛谷/巩固） |

## 站点结构（分章懒加载）

```
C_learn/
├── index.html              # 外壳（约 130KB）：顶栏 / 目录树 / 封面，不含正文
└── assets/
    ├── style.css           # macOS 风格视觉系统
    ├── fonts.css           # 字体声明
    ├── app.js              # 交互（目录折叠、分章加载、搜索、主题、阅读进度）
    ├── manifest.js         # 章节清单：片段顺序 + 锚点 → 片段映射
    ├── search-index.js     # 全文搜索索引（首次搜索时才加载）
    ├── fonts/              # 按文档字符集子集化的 woff2（Inter / Noto Sans SC / JetBrains Mono）
    └── content/            # 正文按章节拆分的 47 个 HTML 片段（约 1.4MB）
        ├── 第-0-篇-总览与速查.html
        ├── 第-9-章-指针.html
        ├── hm-03-循环与经典数值题.html
        └── …
```

- **正文按章节分文件**：`index.html` 只含外壳，跳转到哪章就加载哪章，向下滚动自动续载下一章——想单独修改某个章节，直接编辑 `assets/content/` 里对应文件即可
- 搜索索引构建期预生成（`search-index.js`），运行时按需加载
- 无任何框架与外部依赖，字体已子集化，**深浅色主题跟随系统、可手动切换**
- 阅读进度自动保存（localStorage，按锚点记录）

## 本地预览

正文通过 `fetch` 分章加载，需通过 HTTP 访问（**直接双击 index.html 无法加载正文**，页面会有提示）：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 部署

整个目录（index.html + assets/）即是完整站点，可托管到 GitHub Pages、Vercel、Netlify 等：

- **GitHub Pages**：仓库 Settings → Pages → 分支选 `main`、目录选 `/ (root)`
